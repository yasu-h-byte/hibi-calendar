# 事務業務マニュアル（森田さん向け）

> **目的**: 奥寺さん・佐藤さんから引き継ぐ事務の仕事（給与締め・有給・道具代・請求）を、この1冊で毎日・毎月こなせるようにする
> **対象読者**: 森田さん（事務担当）
> **前提となる体制**: 給与計算・給与明細・振込は日比建設・HFU とも **キャシュモへ委託**（9月分から）。
> 森田さんの担当は「システムでの日常事務」「月次の締め」「キャシュモへの資料提出」「請求書の発行申請」まで。
> **作成日**: 2026年9月2日
> **最終更新**: 2026年10月8日
> **公開版**: `/manual-morita.html`（資料一覧から開けます）

### 1-4. 通知ベル（🔔）

左上の名前の横の 🔔 に、森田さんの仕事に関係するお知らせが出ます。

- **有給の付与日が近い／付与が未処理** → §3-2
- **月締め未完了**（前月がまだ締められていない。**翌月11日から**出ます。月初から10日までは出ません） → §2-4
- **有給申請 ◯件／帰国申請 ◯件**（承認待ち。承認は職長と政仁さん。森田さんは止まっていないかを見る） → §3-7
- **在留期限**が近い人 → 本人・職長・靖仁さんに知らせる

### 1-5. 人員マスタで気をつけること（2026-10-03〜）

メニュー「人・書類」→「人員マスタ」。行を押すと右にその人の内容が開きます。

- **給与欄（日額・時給・月給・号俸・旧ルール）は、新しく登録するときも代表だけ**が入れます。森田さんが入れようとすると「給与欄を入れられるのは代表だけです」と断られるので、給与欄を空にして登録し、靖仁さんに伝えてください
- **空にして保存すると消えます**（退職日・在留期限・メモなど）。間違えて入れた退職日は、空にして保存すれば取り消せます
- **退職日を先の日付で入れた人は、その日まで在籍のまま**です。一覧に「退職予定（◯月◯日）」の札が付き、出面・書類庫・評価にはそのまま出ます
- 代表・政仁さん・役員・事務の**スマホURL（合言葉）は代表だけが発行**します（一覧に「代表のみ」と出ます）。スタッフ・職長の分はこれまでどおり森田さんも出せます
- 右のパネルを閉じるとき、**保存していない変更があると「閉じますか？」と確認**が出ます。保存するなら「キャンセル」で戻って「保存」

## 2. 給与締め

給与の計算そのものはキャシュモの仕事です。森田さんは**正しい出面で月を締めて、資料を渡すところまで**が担当です。

### 2-1. 出面の事務補助（月の途中〜月初）

ベトナム人は本人のスマホ入力、日本人は職長の入力が基本です。森田さんは**入力漏れのフォローと過去日の修正**をします。

**入力のしかた**: メニュー「出面・勤怠」→「出面入力」→ 現場と月を選び、人と日のマスに入力。

| 入力値（日本人） | 意味 |
|---|---|
| `1` / `0.5` | 出勤（1日）／半日 |
| `有` | 有給休暇 |
| `試` | 試験（出勤扱い） |
| `欠` | 欠勤。**月給制の人（濱上さん）はこの記録がある日だけ欠勤控除**されます（空欄では引かれません） |
| 下段の数字 | 残業時間（0.5時間単位） |
| 空欄 | 休み／未入力 |

- **保存は自動**です（保存ボタンはありません）。Enter で次の人の同じ日へ移動します
- **変更履歴と復元**: 消した・上書きした記録は、画面右上の「**変更履歴**」→ 該当行の「**元に戻す**」で復元できます（90日保持。復元も履歴に残るのでやり直せます）
- **同じ日に複数現場**: 同じ人を同じ日に合計1人工を超えて入れるとエラーになります（半日×2現場は OK）
- **ベトナム人の新規入力は本人のスマホが原則**。事務があとから入れられるのは 有給・欠勤・帰国中・0.6補（現場都合休みの休業補償）だけです
- 承認済みカレンダーの休日はグレー、帰国中は「✈帰国」と自動で表示されます
- 「入力できない」と言われたら、その日が職長承認済みでないか・その月が締め済みでないか・**入社前／退職後の日でないか**を確認します（入社前・退職後の日は、どこからも入力できません）
- **「配置外」の印がついた行**が出ることがあります。その現場の配置に入っていないのに入力がある人です（スマホで現場を選び間違えた打刻など）。見つけたら、正しい現場へ移します（分からなければ職長か政仁さんに確認）。配置外の人は、未入力の数・人数には入りません
- **ベトナム人の打刻し忘れ**（本人のスマホ入力が無い日の出勤など）は、森田さんは入れられません。気づいたら**代表（靖仁さん）か政仁さん**に伝えてください。この2人だけが、昨日までの日をさかのぼって入れられます
- **政仁さんの最終承認がついた日**は、森田さんも職長も直せません（2026-10-03〜）。直す必要があれば政仁さんか靖仁さんに頼みます
- **0.6補（会社の都合の休み）は、カレンダーで仕事の日にだけ**入れられます。休みの日に入れようとすると「仕事の日だけ入れられます」と断られます

### 2-2. 月次集計のチェック（月初）

1. メニュー「給与・締め」→「**月次集計・締め**」を開き、上のタブが「月次集計・締め」になっていることを確認（開くと、締める月＝前月が出ます。「締める月」の印が付きます）
2. 対象の月（前月）を選ぶ
3. 「全体／日比建設／HFU」を切り替えて、一人ずつ **出勤日数・残業・有給・欠勤** がおかしくないか見る
4. 上に黄色や赤の帯「**給与計算に異常（または注意点）があります**」が出ていたら、名前が出ている人の行をクリック → 「計算根拠」で内容を確認。出面の入力ミスなら出面を直す。分からなければ靖仁さんへ
   - 赤い「**異常**」は支給額に影響するもの。黄色い「**注意点**」（9月分から）は、週40時間超・稼働日の空欄・月途中の時給改定の残業・旧契約の日曜や夜勤などの**お知らせで、支給額は変えません**。出面を直すか、そのままでよいか靖仁さんに確認してから締めます
   - **黄色い注意点は「確認した」で帯から外せます**（2026-10-05〜）: 中身を見て「このままでよい」と判断したら、その行の **「確認した」** を押します（ひとことメモを書けます。例:「金額が小さいのでこのまま」「代表に確認済み」）。確認したものは帯とメニューの赤い数字から外れ、下の「**確認済みの注意点 ◯件**」に、誰が・いつ・メモつきで残ります。あとで金額や日数が変わると、もう一度帯に出ます。間違えて押したら「確認を取り消す」。赤い「異常」は確認では消えません（直すまで締められません）
   - 確認していない注意点が残ったまま締めようとすると、「確認していないものが ◯件 あります」と一覧が出ます。戻って確認するか、承知のうえで「それでも締める」（記録に残ります）
5. 「締め（給与確定）後に支給額が変わっています」という帯が出ていたら §2-6 を見る

- 以前あった「📋 前月コピー」ボタン（前月の出面を丸ごと写す保守用）は、2026年10月2日に画面からなくしました
- 外注の人工・金額は、この画面ではなく「原価・収益」で見ます

### 2-3. 所定日数の確認

月次集計の画面の上のほうに所定日数の表示があります。

- 「📅 所定日数: カレンダーから自動取得」と出ていれば、ベトナム人の所定日数は現場の就業カレンダーから自動で入っています
- その横の「**所定日数(旧ルール用)**」の欄は、旧ルールで計算している固定月給の人（フンさん等）の欠勤控除に使います。毎月入れて「保存」
  - 「📅 基準値: ◯日 (日曜以外)」を押すと日曜以外の日数に戻ります。特別休暇がある月はそこから手で引きます
  - 赤字で「⚠ 未設定（フンさんの欠勤控除が計算できません）」と出ていたら、必ず入れて保存
  - **日比建設・HFU のどちらかを締めたあとは変えられません**（締めた会社の確定額が動くため）。直すなら先に締めを解除（§2-6）

### 2-4. 月締め（ロック）

1. 「月次集計・締め」の画面の **日比建設のカード** を見て、本人確認・自動検算のチェックを確かめ、一番下の **「日比建設 の◯月分を締める」** を押す → 「◯◯ の日比建設を月締めしますか？」で「OK」
2. 続けて **HFU のカード** の「HFU の◯月分を締める」も同じように押す（会社ごとに別々に締めます）
3. それぞれのカードが緑の「◯月分は締め済み」になれば完了

**締めの準備カード**: 画面の「締めの準備」カードの「**出面の承認（職長・最終）**」に、承認が足りない **現場×日の件数** と、どの現場の何日かが出ます。月の途中は「月が終わってから数えます」と出ます。

- 9月分から、締める前に次の日すべてに **職長承認と最終承認（政仁さん）** がそろっている必要があります
  - **ベトナム人（外国人）スタッフ**: 出勤の日に加えて、**休み・有給・0.6補の日や、入力のない仕事の日**も
  - **日本人スタッフ**: 出勤・残業の日だけ
- そろうまで締められません。足りない現場の職長と政仁さんに頼みます

**締められないとき**は、理由がメッセージで出ます。次の5つがそろっていないと締められません。

| メッセージの内容 | やること |
|---|---|
| まだ終わっていない月 | 月が終わってから（翌月になってから）締める |
| 出面の承認が済んでいない（職長承認なし・最終承認なしの現場名と日付が出る。9月分から最終承認も必須） | 職長承認はその現場の職長へ、最終承認は政仁さんへ頼む |
| 給与計算の自動検算で異常が残っている | §2-2 の手順4で原因を直す。分からなければ靖仁さんへ |
| 未処理の有給申請が残っている | 職長承認・政仁さんの最終承認（または却下）を頼む（§3-7） |
| 対象月に重なる未処理の帰国申請が残っている | 同上 |

**ベトナム人スタッフの本人確認**: 本人がスマホで「正しい／まちがいがある」を押します。月次集計には一人ずつ次の状態が出ます。

| 表示 | 意味 | やること |
|---|---|---|
| 確認ずみ | 本人が「正しい」を押した | なし |
| まだ | スマホに確認が出ているが、まだ押していない | 本人（または職長）に声をかける |
| 承認待ち | その人の出面の承認（職長・最終）がそろっていないので、スマホにまだ確認が出ていない | 承認がそろえば本人のスマホに出る。先に承認を頼む |
| 期間外 | スマホで確認できるのは、締める前の前の月だけ。それより古い月 | なし（スマホでは確認できない） |
| 要再確認 | 確認したあとで出面が変わった | もう一度本人に確認してもらう |
| 本人から連絡あり | 本人が「まちがいがある」を押した | 出面を見直し、月次集計のバッジから「対応済み」にする |

- **「まだ」「要再確認」の人への催促**: 本人のスマホに確認が出てから **3日たっても押していない人** がいると、締めのカードの下に黄色の帯と **「お願いの文面を作る」** が出ます。押すと、その人たちの名前が入った文（ベトナム語と日本語）が出るので、**「文面をコピーする」** → スタッフのグループ（LINE など）に貼り付けて送ります。日比建設と HFU はまとめて1つの文です。3日たつまでは灰色で「確認を待っています（催促は◯日から）」と出るだけです。承認待ちの人は、まだスマホに確認が出ていないので文に入りません
- 「承認待ち」の人だけのときは、カードは警告になりません
- 締めるとき、確認ずみでない人がいると名前と状態の一覧が出ます。帰国中などでどうしても確認できない人がいれば、承知のうえで「OK」で締められます（記録に残ります）
- 締めると、その月の出面は編集できなくなります
- 🔔 に「月締め未完了」が出ている間は、まだ締めていない会社があります

### 2-5. キャシュモへの資料提出（締めたらすぐ）

メニュー「給与・締め」→「**月次集計・締め**」を開き、上の「**帳票出力**」タブを押して（メニューの検索欄に「帳票」と打っても行けます）、右上で対象月を選びます。

**毎月送るのは会社ごとに2点**です。この2点に、その会社の全員（日本人・ベトナム人）が載ります。

| 毎月送る資料 | ボタン | 中身 |
|---|---|---|
| 月次集計 Excel | 「📊 月次集計 Excel」 | 支給額の内訳（日本人シート／ベトナム人シート）。**参考値**。マネーフォワードに入れる数字 |
| 計算根拠 PDF | 「🔍 計算根拠 PDF」 | 1人1ページの内訳＋日別カレンダー（有給・欠勤の日付）＋自動検算。**参考値**。Excel の裏付け |

手順:
1. 月次集計・締めの日比建設・HFU のカードが両方「締め済み」になっていることを確認（締める前に出した Excel は、先頭に「未確定（締め前）」のシートが入り、ファイル名に【未確定】が付きます。計算根拠 PDF も締める前は表紙に「未確定（締め前）」の印が付きます。**【未確定】の付いたファイルはキャシュモに送らない**）
2. 「📤 キャシュモ提出（毎月の2点・会社別）」の枠で、**日比建設の行**の「📊 月次集計 Excel」を押す → Excel がダウンロードされる
3. 同じ行の「🔍 計算根拠 PDF」を押す → 新しいタブが開くので、印刷（Mac は ⌘+P、Windows は Ctrl+P）→ 送信先「PDFに保存」で保存
4. **HFU の行**でも 2〜3 を繰り返す
5. 4つのファイルをキャシュモへ送る（期限・送り方はキャシュモとの取り決めどおり）
6. キャシュモから計算結果・振込完了の連絡が来たら確認する。システムの参考値と大きくずれていたら靖仁さんへ

**求められたときだけ出す資料**（同じ画面の「📁 根拠書類（毎月は送らない・会社別）」の枠）:

| ボタン | 中身 |
|---|---|
| 📅 勤務予定シフト | ベトナム人の各日・各週の所定労働時間（変形労働時間制の事前の予定） |
| ⏱ 実労働時間明細 | ベトナム人の日別の始業・終業・休憩・実労働時間（残業の根拠） |
| 📋 出面一覧 | 全員の日別の出勤・残業＋勤務時間一覧 |

キャシュモ・社労士・労基署から求められたら出します。同じ画面の下の「🏢 社内用」の枠には、有給管理台帳・カレンダー 周知・同意台帳・外注先向け 出面確認書・歩掛管理表などがあります。

- 各資料にはキャシュモの従業員番号が載ります。新しく入った人の番号をキャシュモからもらったら、「人員マスタ」→ その人の行を押す（右に内容が開く）→「基本」の「**キャシュモ従業員番号**」に入れてください
- 道具代・立替などマネーフォワード側の項目は、これまでどおりマネーフォワードから
- 資料の読み方・変形労働時間制・残業判定の説明は [社労士提出用資料マニュアル](/manual-syaroshi.html) にあります（キャシュモへの説明にも使えます）

### 2-6. 締めたあとで直すとき（解除）

1. 「月次集計・締め」で対象月を選び、日比建設のカードの「**締めを解除**」（HFU なら HFU のカード）を押す → 「OK」
2. 出面などを直す
3. §2-2 のチェックをして、もう一度カードの「◯月分を締める」
4. キャシュモへ提出済みなら、2点を出し直して**差し替えの連絡**をする

- 締めたあとに単価・出面・有給などが変わると、月次集計に「締め（給与確定）後に支給額が変わっています」という帯が出ます。間違いなら元に戻し、正しい修正なら「解除 → 確認 → 締め直し」をしてください

### 2-7. システムの「給与計算」の位置づけ

- 月次集計に出る支給額や提出資料の金額は、**システムの自動計算（参考値）**です。キャシュモの計算結果と大きくずれていないかの確認に使います
- 森田さんが給与を計算する必要はありません。ずれや疑問は靖仁さんへ

## 3. 有給まわり

**付与・時季指定・買取の記録・管理簿は森田さんの仕事。申請の最終承認は政仁さんの仕事**です。

### 3-1. 画面の場所

メニュー「出面・勤怠」→「**休暇管理**」。タブは6つです（2026年10月1日の画面の見直しで名前が変わりました）。

| タブ | 使い方 |
|---|---|
| 有給 | 上に「今やること」（承認待ちの申請・付与の設定が必要な人・年5日の未達）。その下にスタッフごとの付与・繰越・消化・残日数が1人1行。**行を押すと右にその人のパネル**が開き、「付与・調整を直す」「時季指定」「買取を記録」のボタンがあります |
| 申請 | 有給・帰国の申請と、その状況（承認するのは職長と政仁さん） |
| カレンダー | 誰がいつ休むか |
| 月別 | 月ごとの消化状況（日比建設／HFU 別） |
| 付与日 | 付与の起点になる日（基準日）の確認 |
| 帰国 | 帰国中・帰国予定・過去の帰国。登録・期間の変更・復帰日の登録もここ（§3-8） |

右上のボタン: 「🔧 メニュー」（手動付与など例外の操作）／「**管理簿（Excel）**」。

- 役員・事務は有給管理の対象外なので一覧に出ません。出向中の人も出ません
- 消化日数は出面の「有」から自動で数えます（直接は変えられません）

### 3-2. 有給の付与（お知らせが来たら）

付与の時期が来ると、2か所にお知らせが出ます。どちらから付与しても同じです。**自動では付与されません**。

**A. 休暇管理の画面上のバナーから（まとめて付与。付与日が来た人がバナーに出ます）**

> 2026年10月から、日本人も**入社6ヶ月後に初回・その後は前回の付与日から1年ごと**に付与します（10月1日にそろえません）。これまで10月1日に付与している人は、そのまま毎年10月1日です。

1. 「休暇管理」→「有給」タブの上の「今やること」に「**付与の設定が必要 ◯名**」のカードが出ている（名前も出ます）
2. カードの「**内容を確認して付与する**」を押す → 付与する人の一覧が開く
3. 一人ずつ **付与日** と **付与日数**（勤続年数から法定の日数が入っています）を確認
   - 「⚠️ 要確認」が付いている人は、入社日などを確認してから
   - 今回付与しない人は「付与する」のチェックを外す
4. 「**一括付与する（◯名）**」を押す

**B. 🔔 通知ベルから（一人ずつ）**

- 付与日が近い人は「◯◯の有給付与日が近づいています」と出ます（まだ押すボタンはありません）
- 付与日を過ぎると「◯◯の有給付与が未処理です」に変わり、「**◯日付与する**」ボタンが出るので押します

付与日数（法定）: 勤続6ヶ月 10日／1年6ヶ月 11日／2年6ヶ月 12日／3年6ヶ月 14日／4年6ヶ月 16日／5年6ヶ月 18日／6年6ヶ月〜 20日。繰越は自動で計算されます（日本人は繰越なし）。月末（29〜31日）に入社した人も、この表どおりの日数で付与されます（2026-10-03 修正）。

- **付与が遅れると、スタッフは有給を申請できません。** 期が終わって次の付与がまだの間は、本人のスマホに「次の付与の手続き待ち」と出て申請が止まります。付与するとすぐ申請できるようになるので、お知らせが出たら早めに付与してください

### 3-3. 手動付与（例外のときだけ）

過去分のさかのぼり・特別な付与・補正のときだけ使います。通常の付与は §3-2 で行います。

1. 「休暇管理」右上の「**🔧 メニュー**」→「✏️ 例外オペレーション」の「手動有給付与」→「**+ 付与する**」
2. 対象者・付与日・付与日数を入れる（下に自動計算のプレビューが出ます）
3. 「**付与**」を押す

- 同じ画面の「保守ツール」（データ正規化・繰越再計算・時効処理）は通常使いません。触る前に靖仁さんへ

### 3-4. 年5日の確認と時季指定

年10日以上付与された人には、1年で最低5日の有給を取らせる義務があります。

**確認のしかた**
- 「ダッシュボード」に「**有給5日義務が未達 ◯名**」と出ます（取得期限が近いのに5日に届いていない人）
- 「休暇管理」→「一覧」の消化日数でも確認できます
- 日本人は 2026年10月1日付与分から「付与から半年たって5日未満」で警告が出ます。ベトナム人は従来どおりです

**時季指定（会社が日を決めて有給を取らせる）のしかた**
1. 本人・職長と相談して休む日を決める
2. 「休暇管理」→「有給」タブ → その人の行を押す（右にパネルが開く）
3. パネルの「**時季指定**」を押す（「有給日を直接入力」の画面が開きます）
4. 指定日（「+ 日付を追加」で複数日）・対象現場（その日の所属現場）を入れ、備考に「**年5日取得義務対応（時季指定）**」と書く
5. 「帰国期間(✈️)を上書きする」は、帰国中の日でなければ関係ありません（そのままで可）
6. 「**有給を記録する**」→ 確認で「OK」 → 出面に有給が自動で入り、履歴に残ります

- その日に別の現場の出面が入っているとエラーになります（出勤と有給の二重払い防止）。先に出面を確認してください
- 帰国期間中の日でも、現場カレンダーの稼働日なら有給を入れられます（本人のスマホ申請でも、この手順での代理入力でも可）

### 3-5. 買取の記録

- **日本人の期末買取（9月30日時点）**は、政仁さん・靖仁さんが賞与を確定すると**自動で記録**されます。森田さんの手入力は不要です
  - 買取は「支給日の時点で**終わっている期**」の残りで記録されます（新しい期の残数は減りません）。休暇管理の「有給」タブでは、その人の内訳に「前の期の残り」として点線の行で出ます
  - 自動記録に失敗した人だけ画面に表示されるので、その人だけ下の手順で記録します
  - 2026年10月1日付与分からは、買取できるのは「**残日数 − 5日**」まで（5日は必ず取らせる）
- **退職時の清算**（日本人・ベトナム人とも）は森田さんが記録します

手順:
1. 「休暇管理」→「有給」タブ → その人の行を押す（右にパネルが開く）
2. パネルの「**買取を記録**」を押す
3. 買取理由（「期末買取（9/30時点）」「退職時清算」「その他」）・買取日数・買取金額（任意）を入れる
4. 「**買取を記録する**」→ 確認で「OK」

- 同じ期に買取が二重に入らないよう、右のパネルの「記録」（買取・時季指定の履歴）を先に確認してください

### 3-6. 有給管理簿（台帳）の出力

1. 「休暇管理」右上の「**管理簿（Excel）**」を押す
2. 出したいものを選ぶ: **日比建設**／**HFU**（会社ごと・社労士や監督署への提出用）／**日本人スタッフ**／**ベトナム人スタッフ**（両社まとめて）
3. Excel（有給管理簿_日比建設_日付.xlsx など）がダウンロードされる

中身（2026-10-05 に作り直し）:

- **一覧表**（先頭のシート）: 全員を1人1行で、今の期の基準日・付与・繰越・取得・残・**年5日の取得**（達成／あと◯日・期限）。足りない人は赤で出ます。日々の確認はこの1枚で足ります
- **個人票**（1人1シート）: 氏名・入社日／期ごとに 基準日（付与日）・付与日数・繰越・有効期限／**取得した日（1日ずつ）**／取得日数・残日数・年5日の取得。「◆」は会社の時季指定、「（予）」は承認済みの予定です
- **買取記録**（会社ごと・ベトナム人の出力だけ）

- ふつうは「今の期と前の期」だけが出ます。監督署の調査などで過去の期もすべて要るときは「**全期間を出す（保存用）**」にチェックを入れてから選びます
- 取得日数は出面の「有」から数えています。出面に無い取得（システム移行前の分）がある人は、個人票に「ほかに、出面に記録の無い取得が ◯日」と出ます
- 退職した人も、保存期間（退職から5年）のあいだは載ります（年5日の欄は「退職」）
- システムを使い始める前（2025年9月より前）に始まった期は、取得した日がシステムに無いので「紙の管理簿」と出ます。その期は紙の管理簿を見てください
- 「月次集計・締め」の「帳票出力」タブの「有給管理台帳」からも、会社別に同じものが出せます

### 3-7. 申請の状況確認と声かけ

申請は **スタッフ（スマホ）→ 職長承認 → 政仁さんが最終承認** の2段階です。森田さんは承認しませんが、**止まっている申請がないか**を見て声をかけます。

1. 「休暇管理」→「**申請**」タブ（「ダッシュボード」の「申請」カードは件数と一覧だけで、「休暇管理で処理する」を押すとこのタブが開きます。🔔 の「有給申請 ◯件／帰国申請 ◯件」からも）
2. 「職長承認待ち」が続いている → その現場の職長に声かけ
3. 「最終承認待ち」が続いている → 政仁さんに声かけ

- 最終承認されると出面に自動で入ります（有給＝「有」、帰国＝「帰国中」）
- **未処理の申請が残っていると月締めができません**（§2-4）。月初の締めの前に必ず確認
- スタッフが「間違えて申請した」と言ってきたら: 職長承認の前なら本人がスマホで取り消せます。職長承認のあとは政仁さんに回してください（森田さんは却下・取消をしません）
- 出面の「有」を出面入力で直接消すと、申請だけ承認済みのまま残ります。承認済みの有給をやめるときは、政仁さんに申請タブの「↩️ 取消」を頼んでください
- 申請した日に本人の出勤の入力がある（または職長承認が済んでいる）ときは、承認する人に「それでも有給で上書きしますか？」と確認が出ます（2026-10-03〜）。出勤が正しいなら却下、有給が正しいなら上書きで承認。迷ったら職長に確かめてもらいます

### 3-8. 帰国まわり

- 帰国の申請も有給と同じ2段階承認です。最終承認されると、帰国期間の出勤日に「帰国中」が自動で入ります（人工にも欠勤にも数えません）
- 「✈️ 帰国情報」タブで、帰国中・帰国予定・過去の帰国を確認できます
- **帰国情報の登録・期間の変更・「復帰日を登録」は森田さんも補助的にできます**（2026-09-26〜）。給与の按分に直結するので、**本人・職長・政仁さんから連絡を受けたときだけ**操作してください
  - 急な帰国で申請が出せない → 「✈️ 帰国情報」→「**＋ 新規登録**」（戻る日が決まっていなければ「復帰未定」）
  - 戻る日が決まった → その人の行の「**復帰日を登録**」
  - 期間が変わった → その人の行の「**編集**」
- 登録したら政仁さんにひとこと伝えてください。**削除**と「出面の帰国表示を点検」（残っている帰国表示の整理）は政仁さん・靖仁さんの操作です

> 制度の詳しい決まり（付与日数の計算・繰越と時効・HFU から移籍した人の勤続通算・帰国中の有給など）は [休暇管理マニュアル](/manual-yukyu.html) を見てください。

## 4. 道具代管理

### 4-1. 決まり

| | ベトナム人 | 日本人（2026年10月1日から） |
|---|---|---|
| 年間予算 | 30,000円 | **100,000円** |
| 期間 | 入社日から1年ごと（一人ずつ。自動で切り替わる） | 10月1日〜翌年9月30日（全員一律） |
| 対象外 | — | 役員・事務・**入社6ヶ月未満**の人（6ヶ月たつと自動で対象に入る） |

- **購入の申請はマネーフォワード**で行います。このシステムに申請機能はありません
- このシステムの役割は「**承認された購入を登録して、残額を管理し、本人のスマホに見せる**」ことです
- 期間の切り替え・予算のリセットは**全自動**。年度の初期化作業はありません

### 4-2. 画面の見方

メニュー「人・書類」→「**道具代管理**」。

- 上の「今やること」: 使いすぎ（残りがマイナス）／残りが少ない（2割未満）／期間が決まっていない。カードを押すとその人だけに絞れます。その下に予算・使った・残りの合計
- 一覧: 会社ごと（日比建設／HFU）に1人1行。区分（日本人は「日本人」）・今の期間・使った割合の棒・残り（使いすぎは赤、残り2割未満は黄色）
- 「現在の期間」に「開始前」のバッジが付いている人は、まだ期間が始まっていない人です（本人の画面には「◯/◯から始まります」と予告が出ます）
- その人の行を押すと、右にその人の画面が開きます（名前で探す欄もあります）

### 4-3. 毎月の作業: 購入を登録する

マネーフォワードで承認された道具の購入を、1件ずつ登録します。

1. 「道具代管理」→ その人の行を押す（右に開く）
2. いちばん下の「**新しい購入を登録**」に入れる
   - **購入日**: 領収書の日付
   - **品名**: 安全帯、工具セット など
   - **金額（円）**: 領収書の金額（税込）
3. 「**+ 追加**」を押す → 上の「購入履歴」に出て、残額が減る。本人のスマホの残額にもすぐ反映されます
4. 「閉じる」で次の人へ

- 予算を超える登録もできますが、残額がマイナスで表示されます。本人に追加の購入を控えるよう伝えてください
- 管理画面の「予算と使用状況」のバーは、80%以上でオレンジ、100%を超えると赤になります

### 4-3b. 電動インパクトの会社半額負担（ベトナム人・2026年10月から）

ベトナム人（技能実習・特定技能）が**電動インパクト**を買ったときは、会社が半分を負担します。

| | 決まり |
|---|---|
| 会社負担 | 購入額の半分。**上限 25,000円** |
| 本人負担 | 購入額 − 会社負担。**本人の道具代の枠から引く** |
| 回数 | **2年に1回まで**（前回の購入日から2年たった日から、また使える） |
| 対象 | 2026年10月1日以降の購入（10月に買った分は、さかのぼって登録できる） |
| 辞めたとき | 返金は求めない |

例: 4万円のインパクト → 会社 20,000円／本人の枠から 20,000円。6万円なら会社 25,000円（上限）／本人の枠から 35,000円。

1. §4-3 と同じように購入日・金額を入れ、その下の「**電動インパクト（会社が半額負担）**」にチェック（品名は空なら「電動インパクト」になります）
2. 「会社 ¥… ／ 本人の枠から ¥…」の内訳を確かめて「**+ 追加**」
3. 購入履歴に緑の「**会社半額負担**」の札が付き、金額の下に会社と本人の内訳が出ます。本人のスマホにも「会社が負担」と出ます

- **すでに普通の購入として登録してしまった電動インパクト**は、購入履歴のその行の「**半額負担にする**」で直せます（外すときは「半額負担を外す」）
- 2年たっていない人・日本人・10月より前の購入は、登録のときに理由が出て止まります
- 会社負担の合計は、画面上の「使った」の説明と、右の画面の「使用済」の横に出ます

### 4-4. 間違えて登録したとき

1. その人の行を押して右の画面を開く
2. 「**購入履歴**」の該当行の「**削除**」→「この購入記録を削除しますか？」で「OK」
3. 正しい内容で登録し直す（§4-3）

### 4-5. 新しく対象になった人（期間の起点日の設定）

新しく入ったベトナム人や、入社6ヶ月を過ぎて対象になった日本人は、一覧の「今の期間」に「**期間が決まっていない**」の札が付いています（上の「今やること」にも出ます）。**起点日を決めるまで購入を登録できません**。

1. その人の行を押す（右に開く）
2. いちばん上の「**期間の起点日**」に日付を入れて「**保存**」→「✓ 保存しました」
   - ベトナム人: 通常は**入社日**
   - 日本人: 起点日をどの日にするか迷ったら靖仁さんに確認
3. 期間が「◯年◯月◯日 〜 ◯年◯月◯日」と表示されれば OK。以後は1年ごとに自動で切り替わります

**すでに使った分があるとき（初回だけ）**: 購入履歴が0件のときだけ「**既存使用分のまとめ登録（初回のみ）**」の黄色い欄が出ます。日付（通常は起点日のまま）・摘要（「既存使用分」）・合計金額を入れて「**まとめて計上**」。

### 4-6. 予算額について

- 予算は区分ごとに決まっています（右上の「区分ごとの予算」）。個人ごとに変えることもできます（管理画面の「予算額（個別変更）」→「予算変更」）
- **予算額は会社の決まりなので、変える必要があるときは靖仁さんに相談**してから変更してください
- 管理画面の「デフォルト: ¥30,000」という表示はベトナム人の既定額です。日本人は 100,000円が正しい予算です

### 4-7. 月末のチェック

| タイミング | 作業 |
|---|---|
| 領収書・MF の承認を受けたとき | 購入を登録（§4-3） |
| 月末 | 上の「今やること」（使いすぎ・残りが少ない）で確認 |
| 期間の終わりが近い人 | 「現在の期間」の終わりが近い人に、残額の案内 |
| 期間の切り替え | 作業なし（自動） |

- 退職した人は自動で一覧から消えます

## 5. 請求まわり

請求書は2種類あります。**出し方が違う**ので注意してください（2026年10月2日〜）。

| 請求書 | 誰へ | 出し方 |
|---|---|---|
| **応援の請求書** | 応援に行った同業者（会社ごと） | **しばらく手作り**（これまでどおり）。出したら「**紙の請求書の控え**」タブに入れて、システムの計算と見比べる（§5-8） |
| **HFU → 日比建設 の請求書** | HFU 所属の人が働いた分（グループ内） | **システムで** 森田さんが申請 → 政仁さんが承認すると発行（§5-1〜5-6） |

システムの請求書は、金額・人工・出面明細が**出面から自動で作られる**ので、手で計算することはありません。応援の請求書をシステムで発行するのは、手作りとの見比べでルールがそろってからです（靖仁さんが決めます。それまで §5-1〜5-6 の手順は HFU → 日比建設 だけに使います）。

### 5-1. 全体の流れ

| 順番 | 誰が | やること |
|---|---|---|
| ① | 森田さん | 月締めのあと、下書きを確認して「発行を申請」 |
| ② | 政仁さん | 🔔 で気づく → 内容を確認して「承認して発行」（直すところがあれば「差し戻し」） |
| ③ | 森田さん | 「✓ 発行済み」になったら印刷（PDF保存）して送る |

申請した時点の内容で止まります（あとで出面を直しても、申請中の請求書は変わりません）。政仁さんが見た内容がそのまま発行されます。

### 5-2. 下書きを確認して申請する（月締めのあと）

1. メニュー「請求・原価」→「**請求・支払**」を開き（最初は「**請求・支払の一覧**」タブ）、右上の月の切り替え（‹ ›）で対象の月にする
2. 上の「今やること」の「**請求書を作る**」を押す。または「会社ごと」の一覧で、請求書が「まだ作っていない」会社の右の「**請求書を作る**」を押す
   - HFU → 日比建設 の請求書は、合計の3枚目「**HFU → 日比建設**」を押す
   - 会社の行を押すと、右に現場ごとの内訳（人工・単価・金額）が開きます
3. 下書き（「DRAFT 下書き」の透かし入り）が開く。次を確認する
   - 宛先の会社名・住所
   - 現場ごとの人工・単価・金額（HFU の請求書は「鳶 残業 ◯h」の行もあります）
   - 2ページ目以降の出面明細（人・日ごとの人工）
4. よければ「**発行を申請（承認へ回す）**」→ 確認で「OK」（請求する日の中に職長承認・最終承認が済んでいない日があると、赤い欄に現場と日が出てボタンを押せません。9月分から）
5. 画面の帯が「**承認待ち — 森田さんが ◯月◯日 に申請**」になり、一覧のバッジも「**承認待ち**」になる（政仁さんの 🔔 に届きます）

- 「請求書を作る」が出ない → その月にその会社への応援がありません（出面を確認）
- 同じ会社・同じ月に「紙の請求書の控え」を入れてあると、下書きに二重請求の注意が出ます（応援の請求書は手作りで出しているので、システムからは申請しません）

### 5-3. 申請を取り下げる（出面を直したい・申請をやめたい）

1. 申請中の請求書を開いて「**申請を取り下げ**」→ 確認で「OK」
2. 出面などを直す
3. もう一度 §5-2 から申請する

- 取り下げた分は番号を使いません（記録だけ残ります）

### 5-4. 差し戻されたとき

- 請求書を開くと、上に**赤い帯**で「差し戻されました（日付）: 理由。直してからもう一度申請してください。」と出ます
- 理由に沿って出面などを直し、もう一度「発行を申請（承認へ回す）」

### 5-5. 発行済みになったら送る

1. 一覧の請求書の札が「**発行済み HC-202609-01**」（HFU は `HFU-…`）に変わったら、行の右の「**請求書を開く**」を押す
2. 「**印刷 / PDF保存**」→ 印刷画面で送信先「PDFに保存」
3. 送る
   - 応援の請求書 → 相手の同業者へ
   - HFU → 日比建設 の請求書 → 社内の経理へ

- 発行済みの請求書は、あとで出面を直しても内容は変わりません
- 発行後に間違いが分かったら、政仁さんに「取り消し」を頼みます（取り消した番号は欠番のまま残ります）。そのあと §5-2 から作り直して申請します

### 5-6. 表示の見方

| 表示 | 意味 | 次にやる人 |
|---|---|---|
| まだ作っていない（赤い札）・「請求書を作る」 | まだ申請していない | 森田さん |
| 承認待ち（青） | 申請済み。番号はまだ無い | 政仁さん |
| 発行済み HC-… / HFU-…（緑の札） | 承認済み。番号が付いた | 森田さん（印刷・送付） |
| 差し戻し・取り下げ（黄色の札） | 差し戻された・取り下げた | 森田さん（直して再申請） |
| 赤い帯「差し戻されました」 | 政仁さんが差し戻した | 森田さん（直して再申請） |
| 「承認待ち」の透かし | 申請中の請求書（印刷して送らない） | — |
| 紙で発行済み（水色の札）・「紙の請求書を見る」 | 手作りで出して「紙の請求書の控え」に入れた | 森田さん（差があれば靖仁さんへ） |

請求書の画面の上には「この会社・この月の発行の記録」（取消・承認待ち・差し戻し・取り下げ）が出ます。

### 5-7. 原価・収益に請求額を入れる

元請などへの請求額（売上）は、「原価・収益」に入れると現場ごとの粗利が出ます。

1. メニュー「請求・原価」→「**原価・収益**」→ 対象の月にする（毎月10日までは、開くと前の月が出ます）
2. 上の「**請求額が入っていない**」のカードを押すと、まだの現場だけに絞れます
3. 現場の行を押す → 右に開いた画面の「**請求額**」の欄に、請求額（**税抜**）を入れて Enter（または欄の外をクリック）で保存
   - 同じ現場に請求書が複数あるときは「**＋ 請求書が複数あるときは行を足す**」で行を増やす（合計が出ます）
   - 入れると粗利が計算し直され、「請求額まだ」の札が消えます

### 5-8. 紙の請求書の控え（応援の請求書・手作り）を入れて見比べる

応援の請求書（畠山組さん・吉本建設工業さんなど）は、しばらくこれまでどおり**手作りで発行**します。出したら、その請求書（PDF か写真）と金額をシステムに入れておくと、**システムの計算と自動で見比べて差が出ます**。差は靖仁さんが手作りのルールに合わせる材料にします。

1. メニュー「請求・原価」→「**請求・支払**」→ 上の「**紙の請求書の控え**」タブを押す（右上のボタンは無くなり、3つのタブで行き来します）
2. 右上の月（‹ ›）を請求した月にして、「**請求書を入れる**」を押す
3. 請求先の会社を選び、請求書のファイル（PDF・写真。出面明細の添付も一緒に）をドラッグするか選ぶ
4. **税込合計**（必須）を入れる。税抜小計・消費税・請求書番号・発行日も分かる範囲で入れる
   - 「明細の行を足す」で、請求書に書いてあるとおりの現場・内容（鳶・土工・鳶 残業）・数量・単価・金額を入れると、現場ごと・人工・残業まで細かく見比べられます
5. 「**入れる**」→ 一覧に1行で出て、「システムと一致」か「差あり」の札が付く。行を押すと、右にどこが違うか（税抜小計・消費税・税込合計・人工の合計・残業時間）が出ます

- 入れると、「請求・支払の一覧」タブの会社ごとの一覧でその会社が「**紙で発行済み**」（水色の札）になります
- **システムで発行済み・承認待ちの月には入れられません**（二重請求の防止。「すでにシステムで…」と出たら、政仁さんに取り消しを頼むか、その月は紙を入れません）
- **税抜小計＋消費税＝税込合計** になっていないと保存できません（「合いません」と出たら請求書の数字を見直す）
- 同じ会社に同じ月で2枚入れたときは、**2枚の合算**でシステムと見比べます（1枚ずつでは必ず差が出るため）
- 入れた内容は行を押して右のパネルの「金額・明細を直す」で直せます（直したら「保存」）。差が出て理由が分からないときは靖仁さんへ（人工と残業の欄の差は、システムが残業を人工に換算しているための見え方の違いのことがあります）

### 5-9. 受け取った外注の請求書を入れる（数か月後から・2026年10月5日〜）

> **紙の書類はすべて DEDURA＋ から入れます**（2026年10月5日〜）。**出した紙は「紙の請求書の控え」、受け取った紙は「受け取った請求書」**。
> - 山岡建設工業へ出した請求書 → 「紙の請求書の控え」で請求先に山岡建設工業を選び、**どの現場の分か**を選ぶ。工種ごとに何枚かに分かれるときは1枚ずつ（工種の欄に「鉄骨」などと書き添え）。同じ現場の全部の合計が、原価・収益で入れた現場の請求額と比べられます
> - 山岡建設工業から届く支払内訳書 → 「受け取った請求書」で種類を「支払内訳書」にして入れる（何か月分載っていても1件で）

外注・同業者から**紙で届いた請求書**は、「請求・支払」の「**受け取った請求書**」タブに入れます（いまは靖仁さんが入れています。森田さんの担当になったら同じ手順で）。

1. 請求書をスキャン（PDF）するか、スマホで写真を撮る（iPhone は「写真を選ぶ」から選べば JPEG で届きます）
2. 「受け取った請求書」で対象月（締めの月）を選び、「請求書を入れる」
3. 請求元の外注先・税込合計を入れ、**1つ目に請求書**、出面の明細などの添付は2つ目以降に入れる（明細を手で打つ必要はありません）
4. 入れるとすぐ「出面 × 単価」と見比べが出ます（支払内訳書は見比べなし）。1万円か3%を超える差は赤（「差」）。現場ごとの人工・単価は行を押すと右に出ます
5. 「まだ届いていない」は、出面で人工があるのに請求書が入っていない外注先です。届いたら行の「入れる」から

- 入れた請求書は、翌朝に**経営コックピット**が読み取り（AI が明細を読む）、帳簿との照合・支払の予定に使います。確定は靖仁さん
- **紙の原本は、スキャン・写真のあとも捨てずに保管**してください
- 削除は政仁さん・靖仁さんだけです（入れ間違えたら声をかけてください）

## 7. 困ったとき

| 困りごと | 対処 |
|---|---|
| ログインできない | パスワードの打ち間違い（大文字・小文字）を確認。だめなら靖仁さんに新しいパスワードを発行してもらう |
| 「もう一度ログインしてください」と出た | もう一度ログインすれば普段どおり使える |
| **出面** を誤って消した・上書きした | 出面入力の右上「変更履歴」→「元に戻す」 |
| スタッフが「入力できない」と言う | その日が職長承認済みでないか、その月が締め済みでないか、入社前・退職後の日でないかを確認 |
| ベトナム人が打刻を忘れていた（出勤した日が空欄） | 代表（靖仁さん）か政仁さんに伝える（さかのぼって入れられるのはこの2人だけ） |
| 出面入力に「配置外」の行が出ている | 現場の選び間違いの打刻など。正しい現場へ移す（分からなければ職長か政仁さんに確認） |
| 締めの準備カードで「出面の承認」が足りない | 出ている現場と日を見て、職長承認はその現場の職長へ、最終承認は政仁さんへ頼む |
| **月締め**ができない | 出てきたメッセージを見る（§2-4 の表）。職長承認・申請の処理が残っていることが多い |
| 月締めのあとで間違いが見つかった | カードの「締めを解除」→ 修正 → もう一度「締める」。キャシュモへ提出済みなら差し替えの連絡も（§2-6） |

## 付録A. 最初に一度だけ（靖仁さんの作業）

森田さんが使い始める前に、靖仁さんが一度だけ行う準備です。

### A-1. 森田さんの個人パスワードを発行する

1. 代表のパスワードでログインする
2. メニュー「管理」→「管理者設定」→ 上のタブ「**🔑 ログイン・権限**」
3. 「**個人パスワード設定**」の欄の **森田さん（事務）** の行にパスワードを入れる（政仁さんの分もここで発行）
4. 下の「**保存**」を押す（1分ほどで使えるようになります）
5. 本人に**口頭か紙で**伝える（グループLINEなど、ほかの人が見られる場所には書かない）

- パスワードは**ほかの人と同じにしない**。職長さんたちが使っている共通パスワードとも別にする
- 森田さんの行が出てこないとき → 人員マスタで森田さんの「職種」が「事務」になっているか確認
- 本人が忘れたときは、同じ画面で新しいパスワードに書き換えて「保存」

### A-2. 請求書に印字する会社情報を保存する

1. 「管理者設定」→ 上のタブ「**🏢 会社・請求書**」
2. **請求書の自社情報**（日比建設）: 住所・登録番号・振込先を入れて「保存」
   （HFU → 日比建設 の請求書の宛先にも、ここの住所が使われます）
3. **HFU → 日比建設 の請求書**: これまでの請求書の内容（会社名・代表者・住所・電話・登録番号・振込先・鳶 30,000円）が入っています。確かめて「保存」
   - FAX 番号は空欄です。必要なら入力
   - 土工のいない月は、土工の単価が空欄でも発行できます

**保存しないと請求書を申請・発行できません**（足りない項目があると、申請のときに何が足りないかが表示されます）。
