# 事務業務マニュアル（森田さん向け）

> **目的**: 奥寺さん・佐藤さんが担ってきた事務業務を森田さんへ引き継ぐための統合マニュアル
> **対象読者**: 森田さん（事務担当）
> **前提となる体制**: 2026年10月以降、日比建設の給与計算・振込業務は HFU 同様 **キャシュモへ委託**。
> 森田さんの担当は「システムでの日常事務」「月次の締め」「キャシュモへの資料提出」まで。
> **作成日**: 2026年9月2日
> **最終更新**: 2026年9月2日

## 3. 日常業務

### 3-1. 出面の事務補助

ベトナム人は本人のスマホ入力、日本人は職長入力が基本。森田さんは**入力漏れのフォローと過去日の修正**を担当します。

- 入力値（日本人）: `1`=出勤 / `0.5`=半日 / `有`=有給 / `試`=試験 / `欠`=欠勤 / 下段の数字=残業h（0.5単位）/ 空欄=休み
- **「欠」**: 月給制（濱上さん）は「欠」の記録がある日だけ欠勤控除されます。空欄では引かれません
- 保存は自動（保存ボタンなし）。Enter で次の人の同じ日へ移動
- **変更履歴と復元**: 誤操作は画面右上「変更履歴」からワンクリックで復元（90日保持）
- **同日多現場ガード**: 同じ人を同日に合計1人工超で入れるとエラー（半日×2現場はOK）
- ベトナム人の新規入力は本人スマホが原則。事務が後付けできるのは 有給・欠勤・帰国中・0.6補（現場都合休みの休業補償）のみ

### 3-2. 有給・帰国申請の承認と有給付与

- 申請の流れ: スタッフ申請 → 職長承認 → **森田さん or 政仁さんが最終承認**（ダッシュボード「勤怠申請」カード or 休暇管理→申請タブ）
- 最終承認すると出面へ自動反映（有給=「有」、帰国=「帰国中」）
- **有給の付与**: 付与時期が来ると通知ベル（🔔）にアラート →「付与する」をワンクリック
- 制度の詳細（残数計算・年5日義務・買取・HFU移籍の勤続通算など）は [休暇管理マニュアル](/manual-yukyu.html) が唯一の参照元

### 3-3. 道具代の管理（佐藤さんから引き継ぎ）

| | ベトナム人 | 日本人（2026-10-01から） |
|---|---|---|
| 年間予算 | 30,000円 | **100,000円** |
| 期間 | 入社日から1年サイクル（個別・自動切替） | 10月1日〜翌9月30日（全員一律） |
| 対象外 | — | 役員・事務・入社6ヶ月未満（6ヶ月経過で自動的に対象入り） |

- **購入の申請はマネーフォワード**。このシステムには申請機能はありません
- 森田さんの作業: **マネーフォワードで承認された購入を、道具代管理画面へ登録**（スタッフ名クリック→モーダル→「新しい購入を登録」に日付・品名・金額）。登録すると本人のスマホの残額に即反映
- 誤登録はモーダルの「購入履歴」から削除→再登録。予算超過はマイナス表示になるので本人に案内
- 期間の切替・予算リセットは**全自動**。年度初期化の作業は不要
- 開始前の人（起点日が未来）は本人画面に「10/1から始まります」と予告表示され、管理画面には「開始前」バッジが付きます

## 4. 月次締め

1. 月次集計（対象月を選択）→「月次集計」タブで出勤日数・残業・有給・欠勤を確認
2. 所定日数が就業カレンダーの稼働日数と一致しているか確認
3. 「チェック」タブの警告を潰す（未入力・未承認が残っていないこと）
4. <b>🔒 この月を締める</b>（日比建設分とHFU分は別々にロック可能）

ロック後は出面が編集不可。間違いが見つかったら 🔓 解除（admin）で戻せます。

## 5. キャシュモへの資料提出

月次集計画面の「**社労士提出用**」セクションから、**会社別（日比建設／HFU）**に3資料を出力して提出します（HFUで従来行っていた提出方法と同じ形です）。

| 資料 | 内容 |
|---|---|
| 📅 勤務予定シフト表（Excel） | 各日・各週の**所定**労働時間（変形労働時間制の「事前に定めた所定」） |
| ⏱ 実労働時間明細（Excel） | 各日の始業・終業・実取得休憩・**実労働時間**と所定外 |
| 🔍 計算根拠PDF | システムの自動計算の内訳（**参考値**。突き合わせ用） |

手順:
1. 月締めロックまで完了していることを確認
2. 月次集計 → 「社労士提出用」→ 会社を選んで3点を出力
3. キャシュモへ送付（提出期限・提出方法はキャシュモとの取り決めに従う）
4. キャシュモの計算結果・振込完了の連絡を確認

> 資料の読み方・変形労働時間制・3段階残業判定の説明は [社労士提出用資料マニュアル](/manual-syaroshi.html) を参照（キャシュモへの説明にもそのまま使えます）。

## 6. システムの給与計算画面の位置づけ

- 月次集計の「給与計算」タブは**自動計算の参考値**です。キャシュモの計算結果と大きくズレていないかの検算に使えます
- 計算ロジックの詳細（雇用形態4区分・端数処理・欠勤控除など）は旧・給与計算マニュアル（アーカイブ）に残してあります。通常業務で読む必要はありません
- ズレや疑問があれば靖仁さんへ

## 7. 年間で知っておくこと

| 時期 | できごと |

## 8. 困ったとき

| 症状 | 対処 |
|---|---|
| 月締め後に間違いが見つかった | 🔓 ロック解除 → 修正 → 再ロック。キャシュモ提出後なら差し替え連絡も |
| 出面を誤って消した・上書きした | 出面画面右上「変更履歴」から復元 |
| スタッフが「入力できない」と言う | その日が職長承認済み（ロック）でないか、月締め済みでないかを確認 |
| 残数・金額がおかしい／画面の不具合 | 靖仁さんへ連絡 |
