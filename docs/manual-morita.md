# 事務業務マニュアル（森田さん向け）

> **目的**: 奥寺さん・佐藤さんから引き継ぐ事務の仕事（給与締め・有給・道具代・請求）を、この1冊で毎日・毎月こなせるようにする
> **対象読者**: 森田さん（事務担当）
> **前提となる体制**: 給与計算・給与明細・振込は日比建設・HFU とも **キャシュモへ委託**（9月分から）。
> 森田さんの担当は「システムでの日常事務」「月次の締め」「キャシュモへの資料提出」「請求書の発行申請」まで。
> **作成日**: 2026年9月2日
> **最終更新**: 2026年9月26日
> **公開版**: `/manual-morita.html`（資料一覧から開けます）

## 0. このマニュアルについて

### 0-1. 引き継いだ4つの仕事

| 分野 | 前の担当 | 森田さんがやること | 章 |
|---|---|---|---|
| **給与締め** | 奥寺さん | 出面の入力漏れフォロー → 月次集計のチェック → 月締め → キャシュモへ資料を送る | §2 |
| **有給まわり** | 奥寺さん | 有給の付与・時季指定・買取の記録・年5日の確認・管理簿の出力・申請が止まっていないかの確認 | §3 |
| **道具代管理** | 佐藤さん | マネーフォワードで承認された購入をシステムに登録・残額の確認 | §4 |
| **請求まわり** | 奥寺さん | 請求書（応援の請求書・HFU → 日比建設）の発行申請と送付・現場の請求額の入力 | §5 |

このマニュアルだけで日々の仕事ができるように書いてあります。制度の細かい決まりを知りたいときだけ、各章の最後にある参考資料を開いてください。

| **キャシュモ** | 給与計算の確定・給与明細・振込（両社とも） |

## 2. 給与締め

給与の計算そのものはキャシュモの仕事です。森田さんは**正しい出面で月を締めて、資料を渡すところまで**が担当です。

### 2-1. 出面の事務補助（月の途中〜月初）

ベトナム人は本人のスマホ入力、日本人は職長の入力が基本です。森田さんは**入力漏れのフォローと過去日の修正**をします。

**入力のしかた**: メニュー「毎日」→「出面入力」→ 現場と月を選び、人と日のマスに入力。

| 入力値（日本人） | 意味 |
|---|---|
| `1` / `0.5` | 出勤（1日）／半日 |
| `有` | 有給休暇 |
| `試` | 試験（出勤扱い） |
| `欠` | 欠勤。**月給制の人（濱上さん）はこの記録がある日だけ欠勤控除**されます（空欄では引かれません） |
| 下段の数字 | 残業時間（0.5時間単位） |
| 空欄 | 休み／未入力 |

- **保存は自動**です（保存ボタンはありません）。Enter で次の人の同じ日へ移動します
- **変更履歴と復元**: 消した・上書きした記録は、画面右上の「**変更履歴**」→ 該当行の「**元に戻す**」で復元できます（90日保持。復元も履歴に残るのでやり直せます）
- **同じ日に複数現場**: 同じ人を同じ日に合計1人工を超えて入れるとエラーになります（半日×2現場は OK）
- **ベトナム人の新規入力は本人のスマホが原則**。事務があとから入れられるのは 有給・欠勤・帰国中・0.6補（現場都合休みの休業補償）だけです
- 承認済みカレンダーの休日はグレー、帰国中は「✈帰国」と自動で表示されます
- 「入力できない」と言われたら、その日が職長承認済みでないか・その月が締め済みでないかを確認します

### 2-2. 月次集計のチェック（月初）

1. メニュー「毎月」→「**月次集計・締め**」を開き、上のタブが「📋 月次集計」になっていることを確認
2. 対象の月（前月）を選ぶ
3. 「全体／日比建設／HFU」を切り替えて、一人ずつ **出勤日数・残業・有給・欠勤** がおかしくないか見る
4. 上に黄色や赤の帯「**給与計算に異常（または注意点）があります**」が出ていたら、名前が出ている人の行をクリック → 「計算根拠」で内容を確認。出面の入力ミスなら出面を直す。分からなければ靖仁さんへ
5. 「締め（給与確定）後に支給額が変わっています」という帯が出ていたら §2-6 を見る

- 「📋 前月コピー」ボタンは**押さない**でください（前月の出面を丸ごと写す保守用のボタンです）
- 外注の人工・金額は、この画面ではなく「原価・収益」で見ます

### 2-3. 所定日数の確認

月次集計の画面の上のほうに所定日数の表示があります。

- 「📅 所定日数: カレンダーから自動取得」と出ていれば、ベトナム人の所定日数は現場の就業カレンダーから自動で入っています
- その横の「**所定日数(旧ルール用)**」の欄は、旧ルールで計算している固定月給の人（フンさん等）の欠勤控除に使います。毎月入れて「保存」
  - 「📅 基準値: ◯日 (日曜以外)」を押すと日曜以外の日数に戻ります。特別休暇がある月はそこから手で引きます
  - 赤字で「⚠ 未設定（フンさんの欠勤控除が計算できません）」と出ていたら、必ず入れて保存

### 2-4. 月締め（ロック）

1. 「月次集計・締め」の画面右上の **「🔒 日比 締め」** を押す → 「◯◯ の日比建設を月締めしますか？」で「OK」
2. 続けて **「🔒 HFU 締め」** も同じように押す（会社ごとに別々に締めます）
3. 上に「🔒 日比 締め済」「🔒 HFU 締め済」の赤いバッジが出れば完了

**締められないとき**は、理由がメッセージで出ます。次の5つがそろっていないと締められません。

| メッセージの内容 | やること |
|---|---|
| まだ終わっていない月 | 月が終わってから（翌月になってから）締める |
| 職長チェック（日次承認）が完了していない（現場名と日付が出る） | その現場の職長に出面の職長承認を頼む |
| 給与計算の自動検算で異常が残っている | §2-2 の手順4で原因を直す。分からなければ靖仁さんへ |
| 未処理の有給申請が残っている | 職長承認・政仁さんの最終承認（または却下）を頼む（§3-7） |
| 対象月に重なる未処理の帰国申請が残っている | 同上 |

- 締めると、その月の出面は編集できなくなります
- 🔔 に「月締め未完了」が出ている間は、まだ締めていない会社があります

### 2-5. キャシュモへの資料提出（締めたらすぐ）

メニュー「毎月」→「**帳票出力**」（月次集計・締めの上のタブ「📑 帳票出力」と同じ画面）を開き、右上で対象月を選びます。

**毎月送るのは会社ごとに2点**です。この2点に、その会社の全員（日本人・ベトナム人）が載ります。

| 毎月送る資料 | ボタン | 中身 |
|---|---|---|
| 月次集計 Excel | 「📊 月次集計 Excel」 | 支給額の内訳（日本人シート／ベトナム人シート）。**参考値**。マネーフォワードに入れる数字 |
| 計算根拠 PDF | 「🔍 計算根拠 PDF」 | 1人1ページの内訳＋日別カレンダー（有給・欠勤の日付）＋自動検算。**参考値**。Excel の裏付け |

手順:
1. 「🔒 日比 締め済」「🔒 HFU 締め済」になっていることを確認
2. 「📤 キャシュモ提出（毎月の2点・会社別）」の枠で、**日比建設の行**の「📊 月次集計 Excel」を押す → Excel がダウンロードされる
3. 同じ行の「🔍 計算根拠 PDF」を押す → 新しいタブが開くので、印刷（Mac は ⌘+P、Windows は Ctrl+P）→ 送信先「PDFに保存」で保存
4. **HFU の行**でも 2〜3 を繰り返す
5. 4つのファイルをキャシュモへ送る（期限・送り方はキャシュモとの取り決めどおり）
6. キャシュモから計算結果・振込完了の連絡が来たら確認する。システムの参考値と大きくずれていたら靖仁さんへ

**求められたときだけ出す資料**（同じ画面の「📁 根拠書類（毎月は送らない・会社別）」の枠）:

| ボタン | 中身 |
|---|---|
| 📅 勤務予定シフト | ベトナム人の各日・各週の所定労働時間（変形労働時間制の事前の予定） |
| ⏱ 実労働時間明細 | ベトナム人の日別の始業・終業・休憩・実労働時間（残業の根拠） |
| 📋 出面一覧 | 全員の日別の出勤・残業＋勤務時間一覧 |

キャシュモ・社労士・労基署から求められたら出します。同じ画面の下の「🏢 社内用」の枠には、有給管理台帳・カレンダー 周知・同意台帳・外注先向け 出面確認書・歩掛管理表などがあります。

- 各資料にはキャシュモの従業員番号が載ります。新しく入った人の番号をキャシュモからもらったら、「人員マスタ」→ その人の「編集」→「**キャシュモ従業員番号**」に入れてください
- 道具代・立替などマネーフォワード側の項目は、これまでどおりマネーフォワードから
- 資料の読み方・変形労働時間制・残業判定の説明は [社労士提出用資料マニュアル](/manual-syaroshi.html) にあります（キャシュモへの説明にも使えます）

### 2-6. 締めたあとで直すとき（解除）

1. 「月次集計・締め」で対象月を選び、「**🔓 日比 解除**」（HFU なら「🔓 HFU 解除」）を押す → 「OK」
2. 出面などを直す
3. §2-2 のチェックをして、もう一度「🔒 日比 締め」
4. キャシュモへ提出済みなら、2点を出し直して**差し替えの連絡**をする

- 締めたあとに単価・出面・有給などが変わると、月次集計に「締め（給与確定）後に支給額が変わっています」という帯が出ます。間違いなら元に戻し、正しい修正なら「解除 → 確認 → 締め直し」をしてください

### 2-7. システムの「給与計算」の位置づけ

- 月次集計に出る支給額や提出資料の金額は、**システムの自動計算（参考値）**です。キャシュモの計算結果と大きくずれていないかの確認に使います
- 森田さんが給与を計算する必要はありません。ずれや疑問は靖仁さんへ

## 3. 有給まわり

**付与・時季指定・買取の記録・管理簿は森田さんの仕事。申請の最終承認は政仁さんの仕事**です。

### 3-1. 画面の場所

メニュー「毎月」→「**休暇管理**」。タブは6つです。

| タブ | 使い方 |
|---|---|
| 一覧 | スタッフごとの付与・繰越・消化・残日数。行の「**編集**」から時季指定（有給日の直接入力）・買取の記録 |
| 📅 基準日 | 付与の起点になる日の確認 |
| 申請 | 有給・帰国の申請と、その状況（承認するのは職長と政仁さん） |
| 月別 | 月ごとの消化状況（日比建設／HFU 別） |
| カレンダー | 誰がいつ休むか |
| ✈️ 帰国情報 | 帰国中・帰国予定・過去の帰国。登録・期間の変更・復帰日の登録もここ（§3-8） |

右上のボタン: 「🔧 メニュー」（手動付与など例外の操作）／「📊 管理簿出力」。

- 役員・事務は有給管理の対象外なので一覧に出ません。出向中の人も出ません
- 消化日数は出面の「有」から自動で数えます（直接は変えられません）

### 3-2. 有給の付与（お知らせが来たら）

付与の時期が来ると、2か所にお知らせが出ます。どちらから付与しても同じです。**自動では付与されません**。

**A. 休暇管理の画面上のバナーから（まとめて付与。10月1日の日本人一斉付与もこれ）**

1. 「休暇管理」を開くと、上に「🌴 **◯名 に有給付与の時期が来ています**」と出ている
2. 「**内容を確認する →**」を押す → 「有給付与対象（◯名）」の画面が開く
3. 一人ずつ **付与日** と **付与日数**（勤続年数から法定の日数が入っています）を確認
   - 「⚠️ 要確認」が付いている人は、入社日などを確認してから
   - 今回付与しない人は「付与する」のチェックを外す
4. 「**一括付与する（◯名）**」を押す

**B. 🔔 通知ベルから（一人ずつ）**

- 付与日が近い人は「◯◯の有給付与日が近づいています」と出ます（まだ押すボタンはありません）
- 付与日を過ぎると「◯◯の有給付与が未処理です」に変わり、「**◯日付与する**」ボタンが出るので押します

付与日数（法定）: 勤続6ヶ月 10日／1年6ヶ月 11日／2年6ヶ月 12日／3年6ヶ月 14日／4年6ヶ月 16日／5年6ヶ月 18日／6年6ヶ月〜 20日。繰越は自動で計算されます（日本人は繰越なし）。

### 3-3. 手動付与（例外のときだけ）

過去分のさかのぼり・特別な付与・補正のときだけ使います。通常の付与は §3-2 で行います。

1. 「休暇管理」右上の「**🔧 メニュー**」→「✏️ 例外オペレーション」の「手動有給付与」→「**+ 付与する**」
2. 対象者・付与日・付与日数を入れる（下に自動計算のプレビューが出ます）
3. 「**付与**」を押す

- 同じ画面の「保守ツール」（データ正規化・繰越再計算・時効処理）は通常使いません。触る前に靖仁さんへ

### 3-4. 年5日の確認と時季指定

年10日以上付与された人には、1年で最低5日の有給を取らせる義務があります。

**確認のしかた**
- 「ダッシュボード」に「**有給5日義務が未達 ◯名**」と出ます（取得期限が近いのに5日に届いていない人）
- 「休暇管理」→「一覧」の消化日数でも確認できます
- 日本人は 2026年10月1日付与分から「付与から半年たって5日未満」で警告が出ます。ベトナム人は従来どおりです

**時季指定（会社が日を決めて有給を取らせる）のしかた**
1. 本人・職長と相談して休む日を決める
2. 「休暇管理」→「一覧」→ その人の行の「**編集**」
3. 「**🗓 有給日を直接入力**」を押す
4. 指定日（「+ 日付を追加」で複数日）・対象現場（その日の所属現場）を入れ、備考に「**年5日取得義務対応（時季指定）**」と書く
5. 「帰国期間(✈️)を上書きする」は、帰国中の日でなければ関係ありません（そのままで可）
6. 「**有給を記録する**」→ 確認で「OK」 → 出面に有給が自動で入り、履歴に残ります

- その日に別の現場の出面が入っているとエラーになります（出勤と有給の二重払い防止）。先に出面を確認してください
- 帰国期間中の日でも、現場カレンダーの稼働日なら有給を入れられます（本人のスマホ申請でも、この手順での代理入力でも可）

### 3-5. 買取の記録

- **日本人の期末買取（9月30日時点）**は、政仁さん・靖仁さんが賞与を確定すると**自動で記録**されます。森田さんの手入力は不要です
  - 自動記録に失敗した人だけ画面に表示されるので、その人だけ下の手順で記録します
  - 2026年10月1日付与分からは、買取できるのは「**残日数 − 5日**」まで（5日は必ず取らせる）
- **退職時の清算**（日本人・ベトナム人とも）は森田さんが記録します

手順:
1. 「休暇管理」→「一覧」→ その人の行の「**編集**」
2. 「**💰 買取を記録**」を押す
3. 買取理由（「期末買取（9/30時点）」「退職時清算」「その他」）・買取日数・買取金額（任意）を入れる
4. 「**買取を記録する**」→ 確認で「OK」

- 同じ期に買取が二重に入らないよう、編集画面の「💰 買取記録」の履歴を先に確認してください

### 3-6. 有給管理簿（台帳）の出力

1. 「休暇管理」右上の「**📊 管理簿出力**」を押す（「帳票出力」→「🏢 社内用」の「有給管理台帳」からも、会社別に出せます）
2. Excel（有給管理簿_日付.xlsx）がダウンロードされる

中身は4シート: ①管理簿（付与・繰越・消化・残・失効・買取・有効期限）／②取得日一覧／③買取記録／④時季指定。労基署の調査や年1回の確認に使います。

### 3-7. 申請の状況確認と声かけ

申請は **スタッフ（スマホ）→ 職長承認 → 政仁さんが最終承認** の2段階です。森田さんは承認しませんが、**止まっている申請がないか**を見て声をかけます。

1. 「休暇管理」→「**申請**」タブ（または「ダッシュボード」の申請の状況、🔔 の「有給申請 ◯件／帰国申請 ◯件」）
2. 「職長承認待ち」が続いている → その現場の職長に声かけ
3. 「最終承認待ち」が続いている → 政仁さんに声かけ

- 最終承認されると出面に自動で入ります（有給＝「有」、帰国＝「帰国中」）
- **未処理の申請が残っていると月締めができません**（§2-4）。月初の締めの前に必ず確認
- スタッフが「間違えて申請した」と言ってきたら: 職長承認の前なら本人がスマホで取り消せます。職長承認のあとは政仁さんに回してください（森田さんは却下・取消をしません）
- 出面の「有」を出面入力で直接消すと、申請だけ承認済みのまま残ります。承認済みの有給をやめるときは、政仁さんに申請タブの「↩️ 取消」を頼んでください

### 3-8. 帰国まわり

- 帰国の申請も有給と同じ2段階承認です。最終承認されると、帰国期間の出勤日に「帰国中」が自動で入ります（人工にも欠勤にも数えません）
- 「✈️ 帰国情報」タブで、帰国中・帰国予定・過去の帰国を確認できます
- **帰国情報の登録・期間の変更・「復帰日を登録」は森田さんも補助的にできます**（2026-09-26〜）。給与の按分に直結するので、**本人・職長・政仁さんから連絡を受けたときだけ**操作してください
  - 急な帰国で申請が出せない → 「✈️ 帰国情報」→「**＋ 新規登録**」（戻る日が決まっていなければ「復帰未定」）
  - 戻る日が決まった → その人の行の「**復帰日を登録**」
  - 期間が変わった → その人の行の「**編集**」
- 登録したら政仁さんにひとこと伝えてください。**削除**と「出面の帰国表示を点検」（残っている帰国表示の整理）は政仁さん・靖仁さんの操作です

> 制度の詳しい決まり（付与日数の計算・繰越と時効・HFU から移籍した人の勤続通算・帰国中の有給など）は [休暇管理マニュアル](/manual-yukyu.html) を見てください。

## 4. 道具代管理

### 4-1. 決まり

| | ベトナム人 | 日本人（2026年10月1日から） |
|---|---|---|
| 年間予算 | 30,000円 | **100,000円** |
| 期間 | 入社日から1年ごと（一人ずつ。自動で切り替わる） | 10月1日〜翌年9月30日（全員一律） |
| 対象外 | — | 役員・事務・**入社6ヶ月未満**の人（6ヶ月たつと自動で対象に入る） |

- **購入の申請はマネーフォワード**で行います。このシステムに申請機能はありません
- このシステムの役割は「**承認された購入を登録して、残額を管理し、本人のスマホに見せる**」ことです
- 期間の切り替え・予算のリセットは**全自動**。年度の初期化作業はありません

### 4-2. 画面の見方

メニュー「人・賃金」→「**道具代管理**」。

- 上のカード: 対象人数／期間設定済／使用済み合計／残額合計
- 一覧: 会社ごと（日比建設／HFU）に、スタッフ・在留資格（日本人は「日本人」）・現在の期間・予算・使用済・残額・操作
- 「現在の期間」に「開始前」のバッジが付いている人は、まだ期間が始まっていない人です（本人の画面には「◯/◯から始まります」と予告が出ます）
- スタッフ名（または「管理」ボタン）を押すと、その人の管理画面が開きます

### 4-3. 毎月の作業: 購入を登録する

マネーフォワードで承認された道具の購入を、1件ずつ登録します。

1. 「道具代管理」→ スタッフ名を押す
2. いちばん下の「**新しい購入を登録**」に入れる
   - **購入日**: 領収書の日付
   - **品名**: 安全帯、工具セット など
   - **金額（円）**: 領収書の金額（税込）
3. 「**+ 追加**」を押す → 上の「購入履歴」に出て、残額が減る。本人のスマホの残額にもすぐ反映されます
4. 「閉じる」で次の人へ

- 予算を超える登録もできますが、残額がマイナスで表示されます。本人に追加の購入を控えるよう伝えてください
- 管理画面の「予算と使用状況」のバーは、80%以上でオレンジ、100%を超えると赤になります

### 4-4. 間違えて登録したとき

1. スタッフ名を押して管理画面を開く
2. 「**購入履歴**」の該当行の「**削除**」→「この購入記録を削除しますか？」で「OK」
3. 正しい内容で登録し直す（§4-3）

### 4-5. 新しく対象になった人（期間の起点日の設定）

新しく入ったベトナム人や、入社6ヶ月を過ぎて対象になった日本人は、一覧の「現在の期間」が「**未設定**」、操作が「**設定**」になっています。**起点日を決めるまで購入を登録できません**。

1. スタッフ名（または「設定」）を押す
2. いちばん上の「**期間の起点日**」に日付を入れて「**保存**」→「✓ 保存しました」
   - ベトナム人: 通常は**入社日**
   - 日本人: 起点日をどの日にするか迷ったら靖仁さんに確認
3. 期間が「◯年◯月◯日 〜 ◯年◯月◯日」と表示されれば OK。以後は1年ごとに自動で切り替わります

**すでに使った分があるとき（初回だけ）**: 購入履歴が0件のときだけ「**既存使用分のまとめ登録（初回のみ）**」の黄色い欄が出ます。日付（通常は起点日のまま）・摘要（「既存使用分」）・合計金額を入れて「**まとめて計上**」。

### 4-6. 予算額について

- 予算は区分ごとに決まっています（右上の「⚙️ 区分別の予算設定」）。個人ごとに変えることもできます（管理画面の「予算額（個別変更）」→「予算変更」）
- **予算額は会社の決まりなので、変える必要があるときは靖仁さんに相談**してから変更してください
- 管理画面の「デフォルト: ¥30,000」という表示はベトナム人の既定額です。日本人は 100,000円が正しい予算です

### 4-7. 月末のチェック

| タイミング | 作業 |
|---|---|
| 領収書・MF の承認を受けたとき | 購入を登録（§4-3） |
| 月末 | 残額が少ない人・マイナスの人がいないか一覧で確認 |
| 期間の終わりが近い人 | 「現在の期間」の終わりが近い人に、残額の案内 |
| 期間の切り替え | 作業なし（自動） |

- 退職した人は自動で一覧から消えます

## 5. 請求まわり

請求書は **森田さんが申請 → 政仁さんが承認すると発行** されます。金額・人工・出面明細は**出面から自動で作られる**ので、手で計算することはありません。

請求書は2種類あります。
- **応援の請求書**: 応援に行った同業者（会社ごと）へ
- **HFU → 日比建設 の請求書**: HFU 所属の人が働いた分（グループ内）

### 5-1. 全体の流れ

| 順番 | 誰が | やること |
|---|---|---|
| ① | 森田さん | 月締めのあと、下書きを確認して「発行を申請」 |
| ② | 政仁さん | 🔔 で気づく → 内容を確認して「承認して発行」（直すところがあれば「差し戻し」） |
| ③ | 森田さん | 「✓ 発行済み」になったら印刷（PDF保存）して送る |

申請した時点の内容で止まります（あとで出面を直しても、申請中の請求書は変わりません）。政仁さんが見た内容がそのまま発行されます。

### 5-2. 下書きを確認して申請する（月締めのあと）

1. メニュー「毎月」→「**請求書・支払**」を開き、◀ ▶ で対象の月にする
2. 「請求する（応援に行った分）」の表で、請求する会社の右の「**請求書を作る**」を押す
   - HFU → 日比建設 の請求書は、画面の上の「**HFU → 日比建設**」の欄の「請求書を作る」から
3. 下書き（「DRAFT 下書き」の透かし入り）が開く。次を確認する
   - 宛先の会社名・住所
   - 現場ごとの人工・単価・金額（HFU の請求書は「鳶 残業 ◯h」の行もあります）
   - 2ページ目以降の出面明細（人・日ごとの人工）
4. よければ「**発行を申請（承認へ回す）**」→ 確認で「OK」
5. 画面の帯が「**承認待ち — 森田さんが ◯月◯日 に申請**」になり、一覧のバッジも「**承認待ち**」になる（政仁さんの 🔔 に届きます）

- 「請求書を作る」が出ない → その月にその会社への応援がありません（出面を確認）

### 5-3. 申請を取り下げる（出面を直したい・申請をやめたい）

1. 申請中の請求書を開いて「**申請を取り下げ**」→ 確認で「OK」
2. 出面などを直す
3. もう一度 §5-2 から申請する

- 取り下げた分は番号を使いません（記録だけ残ります）

### 5-4. 差し戻されたとき

- 請求書を開くと、上に**赤い帯**で「差し戻されました（日付）: 理由。直してからもう一度申請してください。」と出ます
- 理由に沿って出面などを直し、もう一度「発行を申請（承認へ回す）」

### 5-5. 発行済みになったら送る

1. 一覧のバッジが「**✓ 発行済み HC-202609-01**」（HFU は `HFU-…`）に変わったら、バッジを押して開く
2. 「**🖨 印刷 / PDF保存**」→ 印刷画面で送信先「PDFに保存」
3. 送る
   - 応援の請求書 → 相手の同業者へ
   - HFU → 日比建設 の請求書 → 社内の経理へ

- 発行済みの請求書は、あとで出面を直しても内容は変わりません
- 発行後に間違いが分かったら、政仁さんに「取り消し」を頼みます（取り消した番号は欠番のまま残ります）。そのあと §5-2 から作り直して申請します

### 5-6. 表示の見方

| 表示 | 意味 | 次にやる人 |
|---|---|---|
| 請求書を作る | まだ申請していない | 森田さん |
| 承認待ち（青） | 申請済み。番号はまだ無い | 政仁さん |
| ✓ 発行済み HC-… / HFU-… | 承認済み。番号が付いた | 森田さん（印刷・送付） |
| 赤い帯「差し戻されました」 | 政仁さんが差し戻した | 森田さん（直して再申請） |
| 「承認待ち」の透かし | 申請中の請求書（印刷して送らない） | — |

請求書の画面の下には「この会社・この月の発行履歴」（取消・承認待ち・差し戻し・取り下げ）が出ます。

### 5-7. 原価・収益に請求額を入れる

元請などへの請求額（売上）は、「原価・収益」に入れると現場ごとの粗利が出ます。

1. メニュー「経営」→「**原価・収益**」→ 対象の月にする
2. 下の現場別の表で、その現場の「**請求額**」の欄を押す → 入力欄が開く
3. 請求額（**税抜**）を入れて Enter（または欄の外をクリック）で保存
   - 同じ現場に請求書が複数あるときは「**+ 行追加**」で行を増やす（下に合計が出ます）

## 7. 困ったとき

| 困りごと | 対処 |
|---|---|
| ログインできない | パスワードの打ち間違い（大文字・小文字）を確認。だめなら靖仁さんに新しいパスワードを発行してもらう |
| 「もう一度ログインしてください」と出た | もう一度ログインすれば普段どおり使える |
| **出面** を誤って消した・上書きした | 出面入力の右上「変更履歴」→「元に戻す」 |
| スタッフが「入力できない」と言う | その日が職長承認済みでないか、その月が締め済みでないかを確認 |
| **月締め**ができない | 出てきたメッセージを見る（§2-4 の表）。職長承認・申請の処理が残っていることが多い |
| 月締めのあとで間違いが見つかった | 🔓 解除 → 修正 → 再び 🔒 締め。キャシュモへ提出済みなら差し替えの連絡も（§2-6） |
| 「締め（給与確定）後に支給額が変わっています」と出た | 間違いなら元に戻す。正しい修正なら 解除 → 確認 → 締め直し → キャシュモへ差し替え |
| 「給与計算に異常があります」と出た | 名前の出ている人の行を押して計算根拠を確認。分からなければ靖仁さんへ |
| **有給** の付与のお知らせが出ない・日数がおかしい | 人員マスタの入社日を確認。それでも違えば靖仁さんへ |
| 有給の「有」を入れたのに休暇管理に出ない | 画面を再読み込み |
| 時季指定でエラーになる | その日に別の現場の出面が入っていないか確認 |
| 申請がずっと止まっている | 職長承認待ち → 職長へ、最終承認待ち → 政仁さんへ声かけ |
| スタッフが有給・帰国の申請を取り消したい | 職長承認前なら本人がスマホで取り消し。承認後は政仁さんへ |
| 帰国の日程が変わった・戻る日が決まった | 政仁さんか靖仁さんに登録を頼む |
| **道具代** の一覧で「未設定」になっている | 管理画面の「期間の起点日」を設定（§4-5） |
| 道具代を間違えて登録した | 購入履歴の「削除」→ 登録し直し |
| 道具代の残額がマイナス | 予算超過。本人に追加購入を控えるよう伝える |
| **請求書** で「自社情報が未入力です」と出て申請できない | 靖仁さんに「管理者設定 → 会社・請求書」の入力・保存を頼む（付録A-2） |
| 「単価（鳶）が未入力です」と出る（HFU） | 靖仁さんに「HFU → 日比建設 の請求書」の単価の保存を頼む |
| 「承認待ちの申請があります」と出る | すでに申請中。政仁さんの承認か、取り下げを待つ |
| 「すでに発行済みです」と出る | その月は発行済み。作り直すなら政仁さんに取り消してもらってから再申請 |
| 請求書を作るボタンが出ない | その月にその会社への応援がない（出面を確認） |
| 残数・金額がおかしい／画面の不具合 | 靖仁さんへ連絡 |

## 付録A. 最初に一度だけ（靖仁さんの作業）

森田さんが使い始める前に、靖仁さんが一度だけ行う準備です。

### A-1. 森田さんの個人パスワードを発行する

1. 代表のパスワードでログインする
2. メニュー「管理」→「管理者設定」→ 上のタブ「**🔑 ログイン・権限**」
3. 「**個人パスワード設定**」の欄の **森田さん（事務）** の行にパスワードを入れる（政仁さんの分もここで発行）
4. 下の「**保存**」を押す（1分ほどで使えるようになります）
5. 本人に**口頭か紙で**伝える（グループLINEなど、ほかの人が見られる場所には書かない）

- パスワードは**ほかの人と同じにしない**。職長さんたちが使っている共通パスワードとも別にする
- 森田さんの行が出てこないとき → 人員マスタで森田さんの「職種」が「事務」になっているか確認
- 本人が忘れたときは、同じ画面で新しいパスワードに書き換えて「保存」

### A-2. 請求書に印字する会社情報を保存する

1. 「管理者設定」→ 上のタブ「**🏢 会社・請求書**」
2. **請求書の自社情報**（日比建設）: 住所・登録番号・振込先を入れて「保存」
   （HFU → 日比建設 の請求書の宛先にも、ここの住所が使われます）
3. **HFU → 日比建設 の請求書**: これまでの請求書の内容（会社名・代表者・住所・電話・登録番号・振込先・鳶 30,000円）が入っています。確かめて「保存」
   - FAX 番号は空欄です。必要なら入力
   - 土工のいない月は、土工の単価が空欄でも発行できます

**保存しないと請求書を申請・発行できません**（足りない項目があると、申請のときに何が足りないかが表示されます）。
