# 山岡への請求書マニュアル（大林組の控えから自動で作る）

> **目的**: 山岡建設工業への毎月の請求書（笹塚・IHI などの自社現場）を、大林組の請求書（控え）の PDF から自動で作り、手で数字を写さないで発行する
> **対象読者**: 森田さん（格納・申請）、政仁さん（確認1）、代表（確認2・発行）
> **画面**: メニュー「請求・支払」→ 上のタブ「山岡への請求書」（`/prime-invoice`）
> **作成日**: 2026年10月20日
> **最終更新**: 2026年10月20日
> **公開版**: `/manual-prime-invoice.html`（資料一覧から開けます）

---

## 0. この仕組みでできること

毎月、山岡から「山岡 → 大林組 の請求書（控え）」が契約（工種）ごとに1枚ずつ届きます。枚数は現場の契約の本数で決まります（笹塚は5枚前後、IHI は1枚）。日比建設はその **「今回請求金額計」の 85%** を山岡に請求します。
借受職人の調整があるときは、山岡の「所属元の異なる借受職人給与の控除」のメモ（控除計算書）も付きます。

これまでは森田さんが数字を手で写して山岡の書式に書いていました（2026年9月分で、85% を掛け忘れて 100% のまま出した件がきっかけです）。
この仕組みでは、**PDF を入れるだけ**で次が自動になります。

| 自動でやること | 内容 |
|---|---|
| 読み取り | 控えから 工種・今回請求金額計・消費税・帳票年月日 を読む。控除計算書から 他社借受の切り出し・給与の控除・支払額 を読む |
| 計算 | 工種ごとに「（今回請求金額計 − 他社借受）× 85% − 給与の控除」。消費税と税込も |
| 検算 | 山岡が大林組へ出した人工（控除計算書の内訳）と、DEDURA＋ の出面（前月21日〜当月20日）を並べる |
| 承認 | 森田さんが申請 → 政仁さんが確認1 → 代表が確認2して発行（番号が付く） |
| 印刷 | 山岡の請求書の書式（A4 横・工種ごとに1枚）で印刷・PDF 保存 |

### 流れ

```
森田さん                 政仁さん             代表
控えを入れて作る ──→ 発行を申請 ──→ 確認1 ──→ 確認2して発行 ──→ 印刷して山岡へ
（下書き）              （確認1待ち）      （確認2待ち）    （発行済み・番号）
```

- 代表は「代表が1回で発行」で確認1・確認2をまとめて発行することもできます（急ぐとき）
- 差し戻されたら下書きに戻ります。直して、もう一度申請します

## 2. 森田さんの手順（格納 → 申請）

### 2-1. 画面を開く

メニュー「請求・支払」→ 上のタブ「**山岡への請求書**」。月は既定で前月です（控えは翌月の中旬に届くため）。「‹ ›」で月を変えられます。

![山岡への請求書の画面](/manual-img/prime-invoice/01-page.jpg)

### 2-2. 控えを入れて作る

<div class="step"><div class="step-num">1</div><div class="step-text">右上の「<strong>控えを入れて作る</strong>」を押す</div></div>
<div class="step"><div class="step-num">2</div><div class="step-text">請求先（山岡建設工業）と現場（笹塚 / IHI …）を選ぶ</div></div>
<div class="step"><div class="step-num">3</div><div class="step-text">控えの PDF（その現場の全部の枚）と、あれば控除計算書の PDF を<strong>まとめて</strong>点線の枠にドロップ（または「ファイルを選ぶ」）</div></div>
<div class="step"><div class="step-num">4</div><div class="step-text">「<strong>読み取って下書きを作る</strong>」を押す。数秒で読み取りが終わり、一覧に下書きの行ができる</div></div>

![控えを入れる窓](/manual-img/prime-invoice/02-upload.jpg)

- どれが控えでどれが控除計算書かは、中身を見て自動で判別します（入れる順番は関係ありません）
- 同じ現場・同じ月の下書きがすでにあるときは、新しく作らずその行を開いて「ファイルを足す」を使います

### 2-3. 読み取った内容を確かめる

一覧の行を押すと、下に詳細が開きます。まず**枚の表**を見ます。

![枚の表](/manual-img/prime-invoice/03-sheets.png)

| 列 | 意味 | 確かめること |
|---|---|---|
| 工種（取引件名） | 控えの「取引件名」。帳票No も出る | 枚数が控えの枚数と合っているか。「PDFから読んだ」の印があるか |
| 大林組への請求額 | 控えの「今回請求金額計」（税抜） | 控えの数字と同じか |
| 他社借受の切り出し | 控除計算書の「○○分出面」の人工 × 常用単価（85% を掛ける**前**に引く） | 名前と金額が控除計算書と同じか |
| ×85% | 切り出し後の額 × 85%（端数は切り捨て） | — |
| 給与の控除 | 山岡が直接払った給与（出向者の分。85% を掛けた**後**に引く） | 名前と金額が控除計算書と同じか。給与を見られる人だけに出ます（下の画像では金額を伏せています） |
| 請求額（税抜）・消費税・税込 | 山岡への請求額 | 合計が控除計算書の「日比建設支払額（税別）」と同じか |

**黄色の「読み取りの注意」が出たとき** は、内容を読んで対処します。

| 注意の文 | 意味 | 対処 |
|---|---|---|
| 控除計算書が…どの工種の控えに当たるか分かりません | メモの「計」の金額と同じ控えが無い | 控えが1枚足りないか、別の月のメモ。ファイルを確かめる |
| メモの「日比建設支払額」…円の差があります | 計算と山岡の支払額が合わない | 1〜数円なら山岡の端数処理の違い。大きければメモか控えの読み取りを確かめる |
| 控えの受注者「…」が請求先の会社と違います | 山岡以外の控えを入れた | ファイルを外す |
| 「…」の控えが2枚あります | 同じ控えを2回入れた | 片方を外す |
| PDF を読めませんでした（…） | スキャン画像・壊れたファイル | 元の PDF をもらうか、「直す」で手入力 |

### 2-4. 出面との検算を見る

枚の表の下に「**出面との検算**」が出ます。**大林組への請求額の全枚の合計**と、DEDURA＋ の出面（前月21日〜当月20日）の**総人工 × 常用単価**を比べたものです。

![出面との検算](/manual-img/prime-invoice/04-check.png)

- 差が 3% 以内なら緑、10% 以内なら黄、それ以上は赤。赤が出たら、出面の入力漏れ・配置の間違い（別の現場の人が入っている）・山岡の出来高の査定を疑います
- 足場やコンクリートなど出来高払いの工種は人工と1対1ではないので、この検算は**目安**です。1人工あたりの請求額（請求額合計 ÷ 総人工）も出るので、常用単価と比べて極端に違わないかを見ます
- 控除計算書の内訳（鳶工 ○人・土工 ○人）は、**手間契約1本分だけ**の人工です。出面全体とは比べず、参考として表の下に出します
- 他社から借りた人（志賀さんなど）は出面にいません。出向者（山岡が給与を払う人）は人工に含めています。「人ごとの内訳」で出向の印が付きます

### 2-5. 発行を申請する

内容が合っていれば「**発行を申請（確認1へ回す）**」を押します。申請した時点で内容が凍結され、政仁さんの通知ベルに出ます。

![ボタン列](/manual-img/prime-invoice/05-buttons.png)

<div class="box box-warn">
**押せないとき（鍵の印）**: 人工の期間（前月21日〜当月20日）の中に、職長承認・最終承認が済んでいない日があります。赤い枠にどの日かが出るので、出面の画面で承認を済ませてから申請してください。
</div>

申請のあとに直したいときは「申請を取り下げ」で下書きに戻せます（確認1が済んだあとは、政仁さんか代表に差し戻しを頼みます）。

## 3. 政仁さんの手順（確認1）

<div class="step"><div class="step-num">1</div><div class="step-text">通知ベルの「山岡への請求書の確認1待ち」を押す（または 請求・支払 → 山岡への請求書 で「確認1待ち」の行を開く）</div></div>
<div class="step"><div class="step-num">2</div><div class="step-text">枚の表（控えの金額・切り出し・控除・請求額）と、出面との検算を見る</div></div>
<div class="step"><div class="step-num">3</div><div class="step-text">問題なければ「<strong>確認1を済ませる</strong>」。直してほしいところがあれば「差し戻し」（理由を書く）</div></div>

確認1だけでは発行されません。代表の確認2で番号が付きます。

## 4. 代表の手順（確認2・発行）

<div class="step"><div class="step-num">1</div><div class="step-text">通知ベルの「山岡への請求書の確認2待ち」を押す</div></div>
<div class="step"><div class="step-num">2</div><div class="step-text">内容を見て「<strong>確認2して発行</strong>」。番号（HCP-202609-01 のような形）が付き、内容は変えられなくなる</div></div>

- 急ぐときは、下書き・確認1待ちの状態から「**代表が1回で発行**」で確認1・確認2をまとめて発行できます（記録に「代表（1回で発行）」と残ります）
- 確認1をした人と同じ人は確認2をできません（別の人が確かめる決まり）

## 5. 印刷して山岡へ送る

発行済みの行を開き、「**印刷 / PDF保存**」を押します。山岡の請求書の書式（A4 横）で、工種ごとに1枚ずつ印刷されます。印刷の設定で「横向き」になっていることを確かめてください。社印は印刷したものに押します。

![印刷面](/manual-img/prime-invoice/06-print.png)

下書き・確認待ちの状態でも印刷はできますが、「下書き」「確認1待ち」の透かしが入ります。山岡に送るのは発行済みのものです。

### 5-1. 発行したら原価・収益の請求額にも自動で入る

発行すると、原価・収益の「現場の請求額」がその請求書と同じ額（税抜・工種ごと）に自動で入ります。手で入れ直す必要はありません。
経営コックピットの入金予定もこの額で動きます。

### 5-2. 支払内訳書が届いたら（入金のチェック）

山岡から支払内訳書が届いたら、「受け取った請求書」に種類「支払内訳書」で入れます（支払元＝山岡・対象月・振込額）。
すると「山岡への請求書」の月の画面と、支払内訳書の行に、**発行済みの請求書の税込合計と振込額の見比べ**（一致・ほぼ一致・差）が出ます。
差が出たら、どの現場の分が違うかを支払内訳書と請求書で見比べてください（現場ごとの内訳の照合と帳簿との突き合わせは経営コックピットが行います）。

## 6. 直したいとき

| したいこと | やり方 | できる人 |
|---|---|---|
| 読めなかった枚の数字を入れる・直す | 枚の表の「直す」→ 工種・大林組への請求額・切り出し・控除を入力 → 保存。計算（割合・消費税）は自動 | 森田さん・政仁さん・代表（給与の控除は給与を見られる人だけ） |
| スキャン画像の控えしか無い（枚が読めない） | 「枚を手で足す」→ 控えを見ながら 工種・今回請求金額計 を入力 → 保存。控えの PDF は「ファイルを足す」で添付として残せる | 同上 |
| 請求年月日を変える（控えの帳票年月日に合わせる） | 詳細の見出しの「請求年月日」の日付欄を変える（下書きの間だけ） | 同上 |
| 控えや控除計算書を足す | 「ファイルを足す」→ PDF を入れる。全部のファイルで読み直す | 同上 |
| 間違ったファイルを外す | 「入れたファイル」の「外す」。残りで読み直す（手で直した数字は元に戻る） | 同上 |
| **割合を 85% から変える**（IHI の 90% など） | 「割合を変える」→ % と理由を入れる → 計算し直す。この請求書だけに効く。85% 以外は黄色の印が出る | 森田さん・政仁さん・代表 |
| 申請を戻す | 確認1待ちの間: 森田さんが「申請を取り下げ」。確認1のあと: 政仁さん・代表が「差し戻し」 | — |
| 発行済みを作り直す | 「取り消し」（番号は欠番のまま残る）→ 控えをもう一度入れて新しく作る | 政仁さん・代表 |
| 下書きを消す | 「下書きを削除」（ファイルも消える） | 森田さん・政仁さん・代表 |

![割合を変える窓](/manual-img/prime-invoice/07-ratio.jpg)

<div class="box box-warn">
割合を変えた月は、控除計算書（85% で書かれている）とは合わないので「メモの支払額と合わない」注意が出ます。これは想定どおりです。割合が正しいかだけ確かめてください。
</div>

## 7. 困ったとき

| 症状 | 原因と対処 |
|---|---|
| 「PDF を読めませんでした」 | 紙をスキャンした PDF は文字が無いので読めません。山岡に元の PDF をもらうか、「枚を手で足す」で数字を手入力 |
| 枚が1枚も読めない | 控えの形が違う（大林組以外の元請の書式など）か、スキャン画像。「枚を手で足す」で手入力。代表に知らせてください |
| 「紙の請求書の控え」があるため発行できない | 同じ現場・同じ月の一次への請求書を「紙の請求書の控え」に入れてあると、二重請求になるので止めています。紙の方を消すか、こちらを下書きのままにします |
| 「この会社・この現場・この月は…請求書があります」 | 同じ現場・月に下書き・確認待ち・発行済みがあります。その行を開いて直す・足す・取り消しをします |
| 「給与の控除」が「伏せ」と出る | 給与を見られる人（森田さん・政仁さん・代表）以外には控除の額を出しません。請求額そのものは見えます |
| 承認がそろっていなくて申請できない | 赤い枠の日の職長承認・最終承認を出面の画面で済ませる。前月分の日が含まれることがあります |
| 出面との検算で大きな差 | 出面の入力漏れ（さかのぼり入力は代表・政仁さん）、または山岡の人工の数え方の違い。差の内容を代表に知らせてください |

## 8. 決まり（参考）

- 計算: `floor((今回請求金額計 − 他社借受の人工分) × 割合) − 山岡が払った給与`。割合は既定 85%。消費税は 10%（切り捨て）
- 人工の期間: 前月21日〜当月20日（山岡の出来高調査日は当月末、帳票は翌月15日）
- 請求年月日: 控えの帳票年月日（翌月15日）。請求書の摘要の期間は対象月の1日〜末日
- 番号: `HCP-YYYYMM-NN`（応援の請求書 HC-… とは別の連番。取り消した番号は欠番）
- 同じ現場・同じ月に生きている請求書は1つ
- 詳しい仕様: `docs/prime-invoice.md`（開発者向け）
