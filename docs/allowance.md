# 遠方現場日当・運転手当（2026-10-01 施行）

最終更新: 2026-08-26　※専門家（社労士）レビュー前のドラフト。施行までに照会予定。

コード上の規則の唯一の置き場は **`lib/allowance.ts`**。画面・給与計算・Excel は
すべてそこから導出する。しきい値や逓減ルールを変えるときは必ず allowance.ts と
本ドキュメントを同時に更新すること。

## 1. 遠方現場日当（非課税・実費弁償）

| 項目 | 内容 |
|---|---|
| 基準 | 距離ではなく**所要時間**。現場ごとの「判定値」（分）で機械的に決まる |
| 判定値 | （朝6:00発の実測平均 ＋ 夕17:30発の実測平均）÷ 2 を四捨五入（片道換算） |
| 金額 | 判定値 **80分超: 500円/日**、**120分超: 1,500円/日**（「超」は厳密） |
| 対象日 | 実際にその現場へ行った日。半日(0.5)も満額。夜勤のみ(w=0, ns)も対象 |
| 対象外 | 有給・休み・帰国・試験・**0.6補償（現場都合休＝現場に行っていない）**・役員(job='yakuin') |
| 同日複数現場 | 高い方の現場1回のみ（実データ3ヶ月で発生0件だが防御実装済み） |

### 長期従事の逓減

単身赴任的な固定化を防ぐため、同一現場への従事が長引くと逓減する。

- 起算日 = 施行日(2026-10-01)以降、その worker×site の**最初の対象日**
- 対象日が **30日以上** 空いたら、次の対象日が新しい起算日（リセット）
- 起算日から **満12ヶ月まで全額 → 満24ヶ月まで半額 → 以降 0円**
- カウンタは**保存しない**。毎回出面から導出する（出面の事後修正と常に一致させるため）

### 測定・凍結の運用

- 現場マスタ（/sites）に住所を登録すると、Vercel Cron が Google Routes API で
  朝6:00・夕17:30 の所要時間を自動測定（`app/api/commute/measure/route.ts`、
  日曜は測定しない、`GOOGLE_MAPS_API_KEY` 未設定時は正常スキップ＝手入力運用）
- 朝夕そろったサンプル **10日分** で「凍結」ボタンが押せる（規程の「最初の10営業日」）
- **凍結後の判定値は変更不可**。恣意的な現場指定は非課税（実費弁償）扱いを崩すため、
  しきい値も施行後に動かさない
- 未凍結の現場は日当0円。凍結後にその月を開き直せば自動反映（月次は毎回導出）

## 2. 運転手当（課税）

| 項目 | 内容 |
|---|---|
| 金額 | **片道あたり** 判定値60分未満: 500円 / 60分以上: 1,000円（行き・帰り同額） |
| 未測定の現場 | 暫定500円（凍結後にその月を再計算すれば自動で正しい額になる） |
| 記録 | 出面の日付ヘッダ「運」ボタン → 行き/帰りの運転者をチェック（`drv` フィールド） |
| 選択肢 | その日出面がある人 × 運転の可能性がある人（人員マスタ `canDrive`。未設定の既定は日本人=あり/外国人=なし） |
| 役員 | 日当と違い**対象**（運転は労働の対価のため除外しない） |
| 割増賃金の基礎 | 算入が必要になる見込み。**社労士レビュー後に実装**（未対応） |

## 3. 給与計算への組み込み（実装）

- ゲートは `loadMonthlyAllowances()`（lib/compute.ts）の先頭: **`ALLOWANCE_FROM_YM='202610'`
  未満の月は undefined を返す** → 過去月の給与・原価は1円も変わらない
  （ゴールデンマスターで担保。`calcMonthlyAllowances` 自体は任意の月を計算できる＝
  施行前実データでの検証用。ゲートを純関数側に置かないこと）
- `computeMonthly(..., allowances)` が netPay / salaryNetPay に加算。
  実支給原価組（ベトナム人・完全月給）は既存の「原価=実支給」配賦がそのまま手当込みに、
  日本人日給月給は bySite で現場原価へ直接配賦
- 長期従事の履歴読みは27ヶ月で打ち切り（逓減は満24ヶ月で0円のため結果不変・クォータ対策）
- 配線済み: /api/monthly・締め（自動検算+スナップショット）・Excel(bukake/monthlyExcel)。
  自動検算 I1（内訳合計=支給額）にも手当を算入済み
- 表示: 月次集計の「日当」「運転手当」列・計算根拠モーダル・給与Excel 全シート
  （いずれも 202610 以降のみ表示。過去月の列構成は不変）
- テスト: `__tests__/allowance.test.ts`（規則）+ `__tests__/allowanceIntegration.test.ts`（組み込み）
