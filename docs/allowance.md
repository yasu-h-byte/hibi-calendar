# 遠方現場日当・運転手当

最終更新: 2026-08-28

コード上の規則の唯一の置き場は **`lib/allowance.ts`**。画面・給与計算・Excel は
すべてそこから導出する。ルールを変えるときは必ず allowance.ts と本書を同時に更新すること。

## ⚠️ 現在の施行状況（2026-08-28 代表決定）

| 制度 | 状況 | ゲート定数 |
|---|---|---|
| **運転手当** | **2026年10月1日 施行**（全現場一律・片道1,000円） | `DRIVE_ALLOWANCE_FROM_YM = '202610'` |
| 遠方現場日当 | **保留**（制度を再検討中・時期未定） | `SITE_ALLOWANCE_FROM_YM = null` |

日当は `SITE_ALLOWANCE_FROM_YM` が `null` の間、**現場に判定値が凍結されていても
一切発生しない**（`loadMonthlyAllowances` が判定値マップを空で渡すため）。
再開するときはこの定数に `'YYYYMM'` を入れるだけでよい。

## 1. 運転手当（課税・賃金）— 施行

| 項目 | 内容 |
|---|---|
| 金額 | **全現場一律 片道 1,000円**（行き・帰り同額）。所要時間・距離・現場を問わない |
| 記録 | 出面の日付ヘッダ「運」ボタン → 行き/帰りの運転者をチェック（`drv` フィールド） |
| 選択肢 | その日出面がある人 × 運転の可能性がある人（人員マスタ `canDrive`。既定は日本人=あり/外国人=なし） |
| 役員 | **対象**（運転は労働の対価のため除外しない） |
| 判定値 | **不要**。運転手当のために現場の住所を登録する必要はない |
| 締め後 | 締め済み月の運転記録は変更不可（saveDrivers に月次ロックガード） |
| 割増賃金の基礎 | 算入が必要になる見込み。**社労士レビュー後に実装**（未対応） |

旧案（判定値60分未満500円／60分以上1,000円の2区分）は 2026-08-28 に廃止した。

## 2. 遠方現場日当（非課税・実費弁償）— 保留

再検討中だが、コードとテストは以下の設計のまま残してある（再開時にそのまま使える）。

| 項目 | 内容 |
|---|---|
| 基準 | 距離ではなく**所要時間**。現場ごとの「判定値」（分）で機械的に決まる |
| 判定値 | （朝5:30発の実測平均 ＋ 夕17:30発の実測平均）÷ 2 を四捨五入（片道換算） |
| 金額 | 判定値 **80分超: 500円/日**、**120分超: 1,500円/日**（「超」は厳密） |
| 対象日 | 実際にその現場へ行った日。半日(0.5)も満額。夜勤のみ(w=0, ns)も対象 |
| 対象外 | 有給・休み・帰国・試験・**0.6補償**・役員(job='yakuin') |
| 同日複数現場 | 高い方の現場1回のみ |
| 長期従事の逓減 | 起算日から満12ヶ月→半額、満24ヶ月→0円。対象日が30日以上空くとリセット（毎回出面から導出・非保存） |

### 測定・凍結の仕組み（日当の再開時に使う）

- 現場マスタに住所を登録すると Vercel Cron が Google Routes API で朝5:30・夕17:30 を測定
  （`app/api/commute/measure/route.ts`。日曜スキップ、朝夕そろい10日で自動停止、
  手入力サンプルは上書きしない、`GOOGLE_MAPS_API_KEY` 未設定なら正常スキップ）
- 朝夕そろったサンプル10日分で「凍結」ボタンが押せる。**凍結後の判定値は変更不可**
- 日当が保留の間は住所を登録しなくてよい（登録しても日当は発生しない）

## 3. 給与計算への組み込み（実装）

- ゲートは `loadMonthlyAllowances()`（lib/compute.ts）の先頭。日当・運転手当を**別々に判定**し、
  どちらも無効な月は undefined を返す（過去月の給与は1円も変わらない＝ゴールデンマスターで担保）
- 日当が無効な間は**長期従事の履歴（過去27ヶ月ぶんの出面）を読まない**＝読み取り回数を節約
- `computeMonthly(..., allowances)` が netPay / salaryNetPay に加算。実支給原価組は既存の
  「原価=実支給」配賦がそのまま手当込みに、日本人日給月給は bySite で現場原価へ直接配賦
  （出向者は出向控除にも反映）
- 配線済み: /api/monthly・締め（自動検算+スナップショット）・Excel。自動検算 I1 にも算入済み
- 表示（月次集計の列・給与Excel）は**該当者がいる月だけ列を出す**方式。日当が再開されれば自動で列が復活する
- テスト: `__tests__/allowance.test.ts`（規則）+ `__tests__/allowanceIntegration.test.ts`（組み込み）
