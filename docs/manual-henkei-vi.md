## 内容の構成（HTML版と同一）

1. **変形労働時間制とは**: 1ヶ月単位（労基法32条の2）。2026年5月から適用。毎月カレンダーを事前確定
   （職長作成 → 政仁さん承認 → スタッフ署名）。月の上限 = 暦日数 × 40 ÷ 7（28日=160.0h/29日=165.7h/30日=171.4h/31日=177.1h）
2. **1日の勤務時間**: 所定7h。8:00〜17:00、休憩2h（10:00-10:30 / 12:00-13:00 / 15:00-15:30）。IHI現場は7:30〜16:30
3. **残業とは**: 残業時間は全時間支払われる。「所定外労働手当（×1.0）」＋ 法定外分に「法定外残業手当（＋0.25）」= 合計1.25倍の分解支給
4. **残業の3段階判定**（最重要）:
   - ステップ1（日）: 1日8h超 → 法定外。所定7hのため最初の1h（7→8h目）は割増なし（×1.0のみ）
   - ステップ2（週）: 週合計が `MAX(40h, カレンダー週所定)` 超 → 法定外。週6日=42hの週は42h超のみ（社労士確認済み）。ステップ1計上分は除く
   - ステップ3（月）: 月合計が法定上限（暦日数×40÷7）超 → 法定外。ステップ1・2計上分は除く
   - 月60h超の法定外残業は割増 +0.5（合計1.5倍）
5. **給料のしくみ**（4層構造）: 基本給（時給×20日×7h・固定）／追加所定手当（21日目〜×1.0）／有給日給（20日枠超過分×1.0）／
   所定外労働手当（残業全時間×1.0）／法定外残業手当（+0.25）／深夜（+0.25）／法定休日（1.35・8h超1.60）／
   休業手当（60%）／欠勤控除（時給×7h×欠勤日数）。有給を取っても基本給は減らない
6. **計算例**: 時給1,500円でケースA（22日×7h・法定外4h → ¥232,500）とケースB（18日+有給2日+残業18.5h・法定外1h → ¥238,125）。
   いずれも「全時間×1.0 ＋ 法定外×0.25」の検算付き
7. **FAQ**: 明細が1.25倍に見えない理由（分解支給）／週6日の週に42hまで割増が付かない理由（事前所定）／
   有給と給料／会社都合休の60%補償／確認先（職長・奥寺さん・政仁さん）
8. **まとめ**: 割増率一覧表

## 説明のポイント（説明する側へ）

- 「働いた時間は1時間もなくならない。全部×1.0で払った上で、法定外の分にだけ+0.25を乗せる」が最初に伝えるべき核心。
  明細で「残業手当が少なく見える」誤解は分解支給が原因なので、所定外労働手当と法定外残業手当を足して見せる
- 週6日の週（42h）に割増が付かないのは「事前カレンダー＋署名」があるから。署名の意味とセットで説明する
- 3段階判定は「同じ時間を2回数えない」ことを図（タイムバー・週の表）で見せると伝わりやすい
