# 平均日給の推移（2026-11-14）

代表のねらい: **一人ひとりの給与は毎年上がるが、会社全体の平均は新しい採用で保つ。** それができているかを見るための指標。

- 画面: `/wage-average`（賃金・評価 → 平均日給の推移。メニューの検索「平均日給」）
- 見られる人: 給与を見られる3人だけ（`pay.view`。画面の入口・API・データの三重の鍵）
- 計算: `lib/avg-wage.ts`（純粋な計算）／記録の読み書き: `lib/avg-wage.server.ts`／API: `/api/wage-average`／自動処理: `/api/wage-average/cron`

## 何の平均か

**基本単価**の平均。手当・割増・欠勤・出勤日数は入れない（季節で動かない「単価そのもの」を見るため）。
単価の持ち方が人によって違うので、1日あたりにそろえる。

| 区分 | 単価 | 1日あたり |
|---|---|---|
| 日本人（日給月給・旧契約） | 日額 | そのまま |
| 日本人（月給だけ・新卒など） | 月給 | 月給 × 12 ÷ 310（給料表の「日給 × 310 = 年収」と同じ物差し） |
| 外国人（時給） | 時給 | 時給 × 7時間（給与計算の1日分と同じ） |
| 外国人（固定月給・旧契約） | 月給 | 契約書の「1時間あたりの金額」（月給 × 12 ÷ 2,020時間）× 7時間。時給の人として数える（「月給の人を外す」では外れない） |

- その月の **1日時点** に有効な単価を使う（改定日より前なら「1つ前の単価」）
- 数える人: その日に在籍している人（退職日の当日は在籍）。**役員・事務は数えない**
- 日本人 = 在留資格なし／外国人 = それ以外。会社（日比建設・HFU）と「月給の人を外す」で絞れる

## 記録

- 毎月1日 JST 9:30 の自動処理が `wageRateSnapshots/{YYYYMM}` に全員の1日あたりの単価を残す（失敗は代表の通知ベル）
- 人員マスタは「今の単価」と「1つ前の単価」しか持たないので、**記録しないと過去を再現できない**
- 記録を始める前の月（2025年10月〜）は、人員マスタの「1つ前の単価」からさかのぼって組み立てる（グラフの白抜きの点・参考値）。
  2回以上改定した人や、マスタから消えた人は正確でないことがある
- 2025年9月より前の**日本人**は、給料解説書（Dropbox「仕事関係/経営計画」・毎年10月1日の確定日給）から取り込んだ（2018年10月〜2025年10月・`lib/avg-wage-documents.server.ts`・グラフの四角の点【資料から】）
  - 名前は持たず、人員マスタの id だけ。人員マスタにいない（辞めた）人は負の番号（年をまたいで同じ人は同じ番号）
  - 役員（年収だけの人）は入っていない。給料解説書に載っていない梶原は、今の日給で 2023〜2025年10月に補った。給料解説書2026に載っていたが2025年10月に在籍していなかった1名は外した（代表 2026-11-14）
  - 2025年10月は、日本人は資料（確定した給料表）を正にし、外国人は人員マスタからさかのぼった点を使う。その月の1日に残した記録があれば、そちらが正
  - 外国人の資料は無いので、2024年10月以前は**全体の平均を出さない**（外国人が抜けると全体が高く見えるため）。②の比較も日本人で見る
- 2016〜2017年は「平均給与・年齢表」の年収（役員を含む）しか無いので、まだ取り込んでいない

## 画面の4つ

1. **推移**: 全体・日本人・外国人の平均と目標線（目標は「目標にする月」の全体の平均）。外国人の割合も出す（割合が上がると全体は下がる）
2. **動いた理由**: 前の点から、辞めた人を抜く → 続けている人の昇給 → 新しく入った人を足す、の順にたどる滝グラフ。3つを足すと前後の差に一致する。
   日本人と外国人の比率の変化は「辞めた人」「入った人」に含まれる。比べる2点は「1年前との比較」の一覧から選ぶか、「月を選んで比べる」で自由に選ぶ
   （例: 2026年9月 → 10月で、10月の年次改定の分だけを見る）
3. **月ごとの昇給**: 隣り合う点のあいだに、続けている人の日給が上がった分の合計（円／日）を、日本人と外国人で積み上げた棒と一覧。
   日本人は毎年10月の年次改定、外国人は契約更新・在留資格の移行のたびに上がる。下がった人（直し・契約の変更）は合計に入れず人数だけ数える。
   資料の年（給料解説書）は1年分の合計。2026年11月までは人員マスタの「1つ前の単価」から組み立てているので、その間に2回以上上がった人は古いほうが見えない
4. **必要な採用**: 今の人全員に「1人あたりの昇給」が乗ったあと、目標の平均に戻すのに、入社時の日給で何人採ればよいか。
   `(今の人数 × 昇給後の平均 + 採用 × 入社日給) ÷ (今の人数 + 採用) ≦ 目標` を満たす最小の人数。入社日給が目標以上なら「保てません」。辞める人は入れない
